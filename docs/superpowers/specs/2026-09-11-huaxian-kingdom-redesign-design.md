## 1 背景与目标

### 1.1 现状

- 世界骨架 = **千字谷镇**(唯一舞台,城镇级),外层产品名「魔法语言岛 v2」。
- 世界观规则轻、不上升神话:叫不出名字就使不上劲 + 双层恢复(拼音声音层 → 汉字形状层)。
- 角色班底 4 张一页卡:苏灵灵🦊 / 徐万年🦥 / 皮小闹🦝 / 吴铭🦇;`SpeechRole` **五值**(+ 旁白📖),无群众位。
- 主题命题「叫得出名字,就有人记得你」。
- ch1《徐爷爷忘掉的名字》已落地 18 幕;**另有一份 2026-09-11 ch1 重构 spec(23 幕 / 句型步 / 场景化干扰项)已设计未实现**。

### 1.2 目标(用户要求)

用户原话要点:

1. 苏灵灵 = **普通的、没有长大的红狐狸小女孩**,生活在有魔法的世界,在努力学习魔法。
2. 国度名为 **花仙国**,得名于巨大浮空、外形像花朵的城市 **花仙城**。
3. 花仙国由 **熊猫贵族** 统治:熊猫居花仙城上,城下住其他动物平民。
4. 贵族掌控政治 / 经济 / 军事 / 粮食等一切。
5. 平民须努力学会魔法,才能养活自己、获得财富与地位。
6. 灵灵在学魔法,并**用魔法帮助他人**。

### 1.3 已排除方向(留痕,防反复)

- **社会寓言路线**(制度不公为主线、灵灵挑战贵族秩序)—— 儿童向风险高(触反模式 #19 失败归因人格、说教、现实无力感),用户否决。
- **贵族有台词 / 出场**—— 加 `SpeechRole` 字面量 = 跨语音域 6 处同步 + 立项,且与「温暖童话」调性冲突,用户否决。
- **重写 ch1 事件与词序**—— 5 词因果链是最强结构资产,改则全量返工,用户否决。
- **千字谷 / 字母林退役**—— 存量资产与英语域实现作废,成本不成比例,用户否决。

## 3 世界设定(四栏 + 显影计划)

### 3.1 舞台层级

```text
花仙国(世界 / 国度)
 └─ 花仙城   浮空巨城,外形如花 → 国名由来;熊猫贵族居所;掌政治/经济/军事/粮食
 └─ 城下地面  其他动物平民聚居(千字谷镇等);平民学魔法谋生
      └─ 千字谷镇  汉语域舞台(ch1 现址,保留)
      └─ 字母林    英语域(存量实现,零改动)
```

### 3.2 四栏

| 栏 | 内容 | 状态 |
| --- | --- | --- |
| **如何运作** | 万物有**真名**。真名分三层:**声音层**(拼音)→ **形状层**(汉字)→ **异域真名**(英语 / 字母林)。叫得出真名 → 事物听你调遣(驱动、修复、显现);叫不出 → 使不上劲 | canon(直接复用既有引擎机制) |
| **代价**(不可豁免) | **叫不出、叫错名字 → 事办不成**。⚠ 这是**世界侧叙事代价**,落在角色身上(徐万年办不成事);**玩家侧零惩罚** —— 答错仅重试,沿用「有意设计:不做玩家惩罚」 | canon |
| **禁忌** | **藏名 / 夺名** — 把别人的名字藏起来,那人会被渐渐忘掉,最后没人叫得应。吴铭所为,全篇轻线核心 | canon |
| **地理 / 社会** | 花仙城浮空于上(贵族),城下地面为平民聚居;平民靠学魔法谋生、争取财富与地位。**仅作背景,不演出压迫** | canon(背景) |

### 3.3 显影计划(哪条规则靠谁付代价显形)

| 规则 | 显影位置 | 手段 | 评价 |
| --- | --- | --- | --- |
| 叫不出名字就使不上劲 | ch1 全程 | 徐万年的日常卡壳(人物喜剧) | 演而非讲 ✓ |
| 双层恢复 | ch1 各词 `t*-sound` → `t*-shape` | 叫回名字才办成事 | 最佳(演而非讲) |
| 藏名禁忌 | `settle` 埋点 → 后段章节 | 徐万年一句「这个我天天都记得的呀」忽然忘掉,不解释 | 埋点,待收 |
| 花仙城 / 贵族 | `open` 天幕一瞥(远景,不解释) | 冰山配额:圣经写 10%、演出用 1% | 有意轻量,ch1 不展开 |

> **不显影(有意)**:「贵族也不能豁免代价」等设定只写进世界观,不进台词、不演出 —— 防设定倾泻与阶级说教。

## 5 主题与核心体验

- **核心体验(一个词)**:**「叫响名字」** —— 把「叫不出名字」的日常窘迫,变成「叫得响」的畅快。
- **主题命题**:「**名字叫得响,再平凡的人也有了力量**」(价值:平凡也有力量;因果:叫出名字 → 力量)。**角色不得直接念出。**
- **情感目标**:①「叫得出名字,就有人记得你」(继承旧命题)②「我能帮到人」的自信 ③ 与苏灵灵的伙伴关系 ④ 对藏名的吴铭**好奇而非恐惧**。
- **正反例锚点**:
  - 正:徐万年叫回「台灯」→ 灯亮、屋子暖 ✓;灵灵帮人办成事 ✓
  - 反:吴铭藏尽别人的名字 → 自己也没人叫得应 ✓(轻线,后段兑现)
- **阶层呼应(不控诉)**:花仙城贵族靠出身,城下平民靠「学」;名字之力谁也垄断不了 —— 灵灵的力量来自**学**,不来自出身。**只展示,不说教。**
- **情感曲线**:谷底 = 徐爷爷站在路中什么都想不起来(替一个好人着急的无力);回弹 = 灯亮、屋子暖起来、五个名字一个没落下。

## 9 风险与安全阀

| 风险 | 处置 |
| --- | --- |
| **反模式 #16 玩法-故事打架** | 机制(学词叫名 → 力量)与命题(名字叫得响平凡也有力量)**同向** ✓ —— 这是本设计最大收益,勿在后续章节反向加「掠夺 / 竞争」机制 |
| **反模式 #19 学习失误 = 道德判决** | 答错仅重试;世界侧代价落在**角色**身上,不归因玩家人格 ✓ |
| **阶级议题说教化** | 命题不由角色念出;贵族无台词不出场;不演压迫 ✓ |
| **设定倾泻** | 冰山配额:开场 3 屏零体系旁白;每场最多 1 个新设定;花仙城只在 `open` 一瞥 ✓ |
| **术语漂移** | §4 命名权威先入表再入稿;「花仙国 / 花仙城 / 千字谷镇」各一种写法 |
| **花仙国 / 花仙城 同前缀**(儿童听认风险,撞 bible §3.4「靠听认」纪律) | 强制全称:`花仙国` / `花仙城`;旁白与口语**禁用简写「花仙」**;两者须靠语境区分(国 = 国度、城 = 头顶那座城)。若实听测混淆,回阶段 0 改名 |
| **ch1 双批冲突** | §7 前置约束:锚点改动并入 ch1 重构批次,禁止并行 |
| **星尘 / 称号体系被读作「顺从制度」** | **有意设计**(温暖童话 D1/D8):灵灵目标是帮人不是改制度;若未来要转向社会寓言,须回阶段 0 重锚 |
