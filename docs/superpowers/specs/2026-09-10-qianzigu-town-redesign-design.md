## 1 背景与目标

### 1.1 现状

- ch1《太阳的求救》已落地:18 幕可玩、双层恢复(拼音/汉字)、3 断点、社交 + BOSS + ending + settle,存档落迁移 0005。
- 角色体系**不是全拟人**:太阳☀️/月亮🌙 是天体(圆日/弯月),静默🖤 是无定形黑影。

- 外层名字有三层:产品「魔法语言岛 v2」→ 世界「星语群岛·万象树」→ 汉语世界「千字谷」。

## 3 世界设定

- **舞台**:千字谷镇。一座山谷里的小镇,镇上的人过着普通日子。
- **叙事名称变更**:
  - 产品名「魔法语言岛 v2」**保留**(仓库/产品层面,`CLAUDE.md` 不动)。
  - 叙事内「**星语群岛 · 万象树**」**退役**,不再出现在台词与设定中。
  - 世界 = 千字谷镇,是**唯一舞台**。
- **世界的规则**(轻,不上升神话):**东西叫不出名字,就使不上劲。** 这不是魔法设定,是日常现象 —— 孩子对「想不起那个词」有直接体感。

## 4 角色体系

### 4.1 命名权威(专名只此一份)

| 角色 | 写法 | 读音(TTS) | emoji | 形态 | `SpeechRole` | 位置 |
| --- | --- | --- | --- | --- | --- | --- |
| 向导(主角) | **苏灵灵** | sū líng líng | 🦊 | 小狐狸 | `lingling` | 镇上第一个跟你说话的;承担指令 / 提问 / 情绪 / 交际 |
| 爱忘事的长辈 | **徐万年** | xú wàn nián | 🦥 | 树懒 | `xuwannian` | 慢吞吞,啥都记不太住 —— 轻线的天然接口 |
| 闯祸精 | **皮小闹** | pí xiǎo nào | 🦝 | 浣熊 | `pixiaonao` | 闲不住,每章的麻烦多半由他起头 |
| 反派 · 大名 | **吴铭** | wú míng | 🦇 | 蝙蝠 | `changmo` | 全镇都这么叫他,**以为这就是他的名字** |
| 反派 · 小名 | **小明** | xiǎo míng | — | — | (同 `changmo`) | 街坊熟人间叫的;汉语世界里的**教科书占位名** |
| 反派 · 真名 | **常默** | cháng mò | — | — | (同 `changmo`) | 被忘掉的真名;只在最后一章被叫出来 |
| 叙述位 | 旁白 | — | 📖 | **不是角色**(无立绘) | `narrator` | 过场 / 结果陈述,第三人称 |

> **无「通用群众位」**。旧 `villager`(居民🐾)已删除 —— **每个出声的角色都有姓名与设定**。镇上需要新面孔时按 §4.6 规程逐个立项,不设匿名占位。

**主角 = 苏灵灵**。故事围绕她展开:她的事、她的镇子、她的热心。

**玩家 = 无名搭档**,**不给任何背景设定**(无「搬来」、无「守护者」、无「家」)。苏灵灵对「你」说话(指令 / 提问 / 情绪 / 交际),沿用现有分工「人称即分工」;玩家不出立绘、无台词。**禁止第一人称叙事框架** —— 剧情不是「你」的故事,是苏灵灵的故事。

### 4.2 他有两个叫法,两个都不是他的名字

| 叫法 | 场合 | 含义 |
| --- | --- | --- |
| **吴铭**(大名) | 全镇通用,正式称呼 | 听起来是一个跟「吴先生」一样的正经姓名 —— 叫了很多年,**谁也没意识到那不是他的名字**。谐音「**无名**」;「**铭**」本义 = 把名字刻下来,而他被从名字里抹掉 —— 反讽最狠。 |
| **小明**(小名) | 街坊熟人 | 汉语世界里**最普通的「占位名」** —— 教科书里随便一个小孩就叫小明。全镇叫他小明,等于**从没把他当成一个具体的人**。 |

- 两个叫法**都像真名,都不是真名** —— 这才是「被忘记」的准确形状:不是没人叫他,是**没人叫对过**。
- 高潮处的揭穿因此有力量:**叫了这么久,都不是他的名字。**
- 真名 **常默**(cháng mò):「常常沉默」= 总没人听见。§7.1 的回收点。

### 4.3 撞音复核(儿童靠自己听认人,硬约束)

| 检查 | 结果 |
| --- | --- |
| 角色间声母 | 苏 s / 徐 x / 皮 p / 吴 w / 常 ch —— **五个全不同** ✓ |
| 撞词库读音 | 全部姓名均**不与词库 100 词任一读音重合** ✓(词库含 猫·狗·兔·龟·猴·鸟·猪·马… 等动物词,是主要排除源) |
| emoji 撞词库 | 🦊 狐狸 / 🦥 树懒 / 🦝 浣熊 / 🦇 蝙蝠 —— **均不在词库 emoji 内** ✓(词库动物段 41–60 已全数排除) |
| TTS 多音字 | 全部用字无多音 ✓ |
| ⚠ 已知近似 | **小明 / 小闹**同带「小」字头(xiǎo míng / xiǎo nào)。韵母完全不同,可接受;若试听混淆,改「皮小闹」的字(不动吴铭)。 |

> ⚠ **选角硬规则**:角色 emoji **不得与 `words.ts` 任一条目重复**,否则孩子无法区分「这是角色还是今天要学的词」—— 词库动物段 id 41–60 是主要排除源。原 `居民🐰` 即因此退役,该角色位本身也已删除(§4.1)。

### 4.4 拟人化要求

**所有出场角色均有身体、有脸、有性格。** 太阳☀️/月亮🌙 **不再是角色** —— 它们是词库 id 1、2,回归为「镇上的东西」。
静默🖤 的黑影形态作废,改为拟人蝙蝠 **吴铭**。

### 4.5 角色一页卡(权威位置)

每位登场角色一份 `game-story-writing` 规格的**一页卡**(11 栏:want / need / 伤口 / 谎言 / 弧光三态 / 声纹 / **外貌锚** / 显影计划 / 跨章状态 / 与主角关系)。

- **权威位置:`docs/design/game-story-bible.md`「角色台账」节**(长期 canon,由 §12 后续落地)。
- 本 spec 只留 §4.1 命名权威(专名唯一写法)+ 下方关系图;完整卡**不在此处复制** —— 外貌锚与专名均**只存一处**,复制即漂移源。
- **外貌锚是跨域契约**:故事侧定稿 → 视觉侧与 AI 立绘按锚点合成(`docs/design/game-assets.md` 引用,不复制)。

**关系图(主角 + 3 名常驻)**

```text
              徐万年(施压者 · 轻线接口)
             ╱                          ╲
     苏灵灵 ──── 互为镜像 ────→ 吴铭
             ╲                          ╱
              皮小闹(被照顾者)   ← 缺席却在场:常默的真名
```

- **主题命题**(一句,全篇角色不得念出):「叫得出名字,就有人记得你。」
- 灵灵与吴铭是同一命题的**正反两面** —— 一个怕被忘记所以拼命帮忙,一个已被忘记所以藏起别人的名字。徐万年的失忆给灵灵施压;皮小闹是她「怕被无视」的弱化镜像。

**命名纪律**(儿童靠自己听认角色,硬约束):

- 姓 + 名;新名与**同章已登场角色**声母或字形不得过近。

## 5 学习层如何嵌入叙事

引擎现有的**双层恢复结构**(每词先 `sound` 后 `shape`)**原样保留**,只换叙事含义:

| 引擎现有 | 新叙事含义 |
| --- | --- |
| `sound` 层(拼音) | 这东西的名字**怎么念** |
| `shape` 层(汉字) | 这东西的名字**怎么写** |

**每章的驱动**:某位**具名角色**碰上「**叫不出名字就办不成**」的事 —— 想吃、想用、想去找,可那东西的名字没人记得,它就使不上劲。
**玩家学会 → 叫出来 → 事成。** 学 = 帮忙,**动机不用解释**。

保留项:每词两题、`minCorrect 2`、每题 2 次机会、断点 3 个、社交 1 场、BOSS 1 场、ending + settle —— **全部不动**。

## 6 章节结构契约

### 6.1 骨架(继承,一帧不改)

```
open(这集开场:谁遇上什么麻烦)
  → 5 词 × 双层(sound / shape)= 10 幕
  → 3 断点
  → social(和一位具名角色相处的选择点)
  → boss(本集最大的乱子)
  → ending + settle(收尾 + 钩子)
```

共 **18 幕**。引擎 / 进度 / 存档**零动**。

### 6.2 叙事调整

- 「**BOSS**」在叙事上降级为「一场闹剧 / 一个难关」—— 日常搞笑里不需要挑战者,需要的是一团乱。**结构位不动。**
- **继承现有最强守则**:`词即剧情道具` —— **先排因果链 → 再选词 → 最后写台词**。禁止为迁就词表打乱因果。

### 6.3 防格式疲劳(四轴变化)

20 章同一套流程会腻。每章在四个轴上变化:

| 轴 | 取值 |
| --- | --- |
| 谁的麻烦 | 班底轮换(苏灵灵 / 徐万年 / 皮小闹),每人有常出问题的领域;后续登场的新居民按 §4.6 立项后加入轮换 |
| 麻烦类型 | 吃 / 找 / 修 / 送 / 藏 / 比 / 怕 |
| 情绪档 | 搞笑 → 温情 → 紧张 → 感动,不总是同一个调 |
| 轻线露头 | 大部分章 0–1 个痕迹;**后段才加密** |

### 6.4 分章规则

- 20 章 × 5 词 = **100 核心词**(id 1–100)正好用尽。
- 每章 5 词按**语义场**成组(同一场戏里会被一起用到的东西),优先选能构成**一条因果链**的组合。

## 7 轻线悬念:吴铭在藏名字

**不搞神明,悬念挂在一个人身上。**

| 层 | 内容 |
| --- | --- |
| **单章体验** | 只是一个角色的小怪癖。「咦,我家那东西叫啥来着?」—— 好笑,不吓人。 |
| **多章叠加** | 读者开始发现,**被藏掉名字的地方越来越多**。这才是悬念。 |
| **每章钩子** | 章末留 1 个痕迹(一个没人认识的陌生字 / 一句喊错的名字),**不解释**。 |
| **高潮**(后段) | 玩家找上门 —— **他其实是镇上最早被忘掉的那个人**。他藏别人的名字,是因为没人记得他。 |
| **主题** | 「**叫得出名字,就有人记得你**」—— 与现有 bible 主题命题一脉相承(现有:「叫得出名字,世界才亮得起来」)。 |

### 7.1 真名 = 最后一章的一个词

最后一章的 5 个词里,**有一个就是「常默」**。玩家学会 → 叫出来 → 他回来了。

- 机制上沿用**剧情词**先例:`words.ts` 已有 id 101 升起 / 102 亮 / 103 早上好(为 ch1 添加的剧情词)。「常默」以同机制加入,**不污染核心 100 词**。
- 这是全篇最强一击,且**零新增资源**(词库现成)。

## 8 ch1 重写方案

### 8.1 范围

| 类别 | 内容 |
| --- | --- |
| **保留(一帧不动)** | 18 幕骨架、场景类型(`open`/`task`/`break`/`social`/`boss`/`ending`/`settle`)、断点数 3、`minCorrect 2`、每题 2 次机会、双层顺序 |

### 8.2 ch1 内容:《徐爷爷忘掉的名字》

**驱动机制(不用魔法解释)**:徐万年**就是爱忘事**。他说不出名字的东西,就找不着、办不成。→ 「忘词」是**人物喜剧**,不是世界观规则 —— 孩子完全懂(自己也会忘词)。

**故事**:苏灵灵在路上撞见徐万年爷爷站在道中央卡壳 —— 他忘了自己要干什么、家在哪儿。灵灵只好一路帮他把名字找回来,送他回家。

**5 词 · 因果链**(搬家语义场,全为**核心 100 词**):

| 序 | 词 | id | 为什么需要它 |
| --- | --- | --- | --- |
| 1 | 房子 | 13 | 徐爷爷想不起自己家是哪一栋 |
| 2 | 门 | 7 | 到了家门口,他忘了这叫什么 —— 不知道推还是拉 |
| 3 | 钥匙 | 14 | 开门要钥匙,他口袋里有,叫不出名字就摸不着 |
| 4 | 窗户 | 8 | 进了屋闷得慌,得把窗户打开 |
| 5 | 台灯 | 19 | 天黑了,叫出「台灯」→ 灯亮 → 这一天成了 |

`wordIds: [13, 7, 14, 8, 19]` · `restoreOrder: [13,13,7,7,14,14,8,8,19,19]`

**18 幕 beat 表**:

| 幕 | 发生什么 |
| --- | --- |
| `open` | 旁白冷开场(镇上的早晨)→ 苏灵灵出场 → 撞见徐爷爷站在道中央卡壳 |
| `t1` 房子 | 叫出「房子」→ 徐爷爷想起家在哪 |
| `br1` | 断点 |
| `t2` 门 | 站在家门口,徐爷爷忘了这叫「门」,推也推不动 |
| `br2` | 断点 |
| `social` | **皮小闹登场** —— 他冒冒失失撞了徐爷爷。3 选项:灵灵怎么对他 |
| `br3` | 断点 |
| `t3` 钥匙 | 徐爷爷摸口袋摸不着钥匙 —— 叫出「钥匙」→ 到手 → 开门 |
| `t4` 窗户 | 屋里闷 → 叫出「窗户」→ 打开,阳光进来 |
| `t5` 台灯 | 天黑了 → 叫出「台灯」→ 灯亮,**这一天成了** |
| `boss` | **闹剧**:徐爷爷的记忆被搅成一团,连「门」「钥匙」都混了 → 5 词交错考核,一个个叫回来 |
| `ending` | 灯亮着,皮小闹咋呼,苏灵灵总括 |
| `settle` | 结算 + **轻线痕迹**(下) |

**BOSS 与机制天然吻合**:现有 BOSS 题池 = 全章 5 词交错 —— 叙事上就是「把混成一团的 5 个名字一个个叫回来」。**零引擎改动。**

**轻线痕迹(ch1 只露这一个,不解释)**:一路都在笑徐爷爷忘事。到了章末,徐爷爷忽然说 —— **「不对……这个我天天都记得的呀。」** 苏灵灵愣住。不解释,进结算。
> 「爱忘事的人」忽然忘了他**从没忘过**的东西 —— 只这一句,悬念就埋下了。

### 8.3 方法

沿用现有守则:**先排因果链 → 再选词 → 最后写台词**。

### 8.4 存档处置

**直接作废 ch1 进度**,不写迁移。

- 理由:内容全换,旧断点语义已不存在;写迁移只是把玩家放到一个他看不懂的中途。儿童向 + 内容全换,重玩是正确行为。
- ⚠ **不能靠「自然失配」**(初稿判断有误,已修正):服务端行存的是 `resumeSceneId` + `restoreState`,而新 ch1 **复用同一批场景 id**(`open` / `t1-sound` / … / `settle`)。旧进度会**照常载入**,停在语义已变的幕上,`restoreState` 里还是旧词 id → 半通状态。
- **实现**:客户端 `chapter-progress` 载入时**校验** `restoreState` 的 wordId 是否全部落在 `CHAPTER_1.wordIds` 内;不匹配 → 视为无进度(重置)。**纯客户端、不动 API / DB / 迁移**,且对以后任何一次章节内容变更都成立。
