## 3 「太丑」的两处根因(读码定位,非猜测)

| # | 问题 | 现状落点 | 对策 |
| --- | --- | --- | --- |
| 1 | **满屏白盒子浮在天空渐变上** —— 词石就是白底圆角矩形 + 2px 描边,读作「按钮」不读作「石头」;深度、材质、场景、爽感四样全缺 | `stone.ts:23` `idle` 态 `bg-surface`;`Choice.tsx:100` 无景深层 | 词石改**糖果立体**(实心底边 = 厚度 + 内侧厚度阴影);题区加**景深层**(柔光 / 云 / 落影);答对加**迸星 + 光柱** |
| 2 | **emoji 是彩色位图,不吃 `color`** —— 状态底色与同色系 emoji 糊成一团(🌙⭐🔥 压橙底、🍏🥒 压绿底、🍎🍓 压红底) | `Choice.tsx:117-121` emoji 裸 `<span>` 直压状态底 | **柔光晕托**:emoji 背后垫白色径向柔光 → emoji 可读性与底色彻底解耦(D4) |

**第 2 条是系统性缺陷**,不是个例:每个语义态都有能撞的 emoji。上一轮的解(状态色改不透明 tint)只解决了「底 vs 舞台」,没解决「emoji vs 底」。

## 4 架构

### 4.1 分层切法

**新增(全部 `src/shared/ui/quiz/`,中性 UI,不引 `features/`)**:

| 新文件 | 职责 | 不做什么 |
| --- | --- | --- |
| `Stone.tsx` | 词石的**唯一渲染点**:状态 → 造型 + 晕托 + ✓✗ 角标 + 上浮/抖动/迸星 | 不含判分/选中逻辑,纯受控组件 |
| `SparkBurst.tsx` | 答对迸星:3–5 个 emoji 粒子,`aria-hidden`,存活 ≤600ms | 不管触发时机 |
| `ProgressCrystals.tsx` | 水晶进度条:替代 3 处重复的 `h-2 rounded-full` 圆点行 | 不承担 a11y 进度语义(既有文本进度照旧) |

**新增(词课自有)**:`src/features/lesson/LessonAmbience.tsx` —— 天空柔光 / 云 / 题区落影的装饰层。

> 只服务词课(D5 后千字谷由舞台自备、短教与冷启动无天空),故落 `features/`,不进 `shared/`。

**改**:`stone.ts`(扩态)、`Choice.tsx`、`ListenChoice.tsx`、`MatchGame.tsx`、`WordLesson.tsx`、`LessonEntry.tsx`、`TeachOverlay.tsx`、`ColdStartWizard.tsx`、`index.css`。

**零改**:`scene-ui.tsx`(千字谷跑章)—— 它只消费 `Choice`/`ListenChoice`/`MatchGame`,**代码形状上**无需改动;但**新增能力并不会自动下发到千字谷**(见 §6 分档表勘误)。

### 4.2 材质层的落位(D11,附理由)

**所有新材质(token + `color-mix`)写成 `index.css` 的普通类,不写进 `stone.ts` 的 Tailwind 任意值。**

三条理由,前两条分别是上一轮踩过的坑:

1. **Tailwind v4 扫描器只认源码字面量** —— 上一轮把 `color-mix` 任意值抽成 helper 函数后,产物里三条规则数量归零,而 `npm test` 与 `npm run lint` 全绿,只有 `npm run build` + 查产物 CSS 才暴露。写成普通类则完全不经过扫描器。
2. **暗色模式靠 token 覆盖自动接管**(`index.css:102` 既有约定:无需逐组件 `dark:` 类)。材质若硬编码 hex,暗色下必然错色。
3. 材质是本项目自有的语义层,与既有 `.stage-sky--*` 同类,放同一处维护。

**硬约束:新增材质类一律用 `var(--color-*)` 与 `color-mix(in srgb, var(--color-x) p%, var(--color-surface))`,禁止裸 hex。**

**`stone.ts` 的形态随之微调**:它仍返回类名字符串(纯函数、可单测,`stone.test.ts` 的断言方式不变),但**材质部分由 Tailwind 工具类换成 `.stone--<态>` 普通类**,布局/间距/圆角仍用 Tailwind 工具类。两者在 `cn()` 里拼接。

**唯一例外:金色(D8 炼金物)。** 金色在三主题下恒定 —— 它不是「表面色」而是「炼成物」,与答对/答错的语义色同样保持恒亮。

### 4.3 边界纪律

- `shared/ui/quiz/` 新增文件均为中性 UI,不引 `features/`;`LessonAmbience` 落 `features/lesson/` 内部,不对外导出。
- `useService()` 取用纪律不变(仅 `*Entry.tsx` 与 `app/` hooks);本轮不新增任何 service 调用。
- `architecture.test.ts` 三层边界与注册纪律照常,`npm test` 须绿。

## 6 分档表 —— 哪个面拿哪些东西

**底座(糖果石 / 晕托 / 间距 / 气泡 / 施法钮)四面完全一致**,差别只在上层。

| 能力 | 词课 | 千字谷跑章 | 短教 | 冷启动 |
| --- | --- | --- | --- | --- |
| 糖果石 + 柔光晕托 + 间距 | ✓ | ✓ | ✓ | ✓ |
| 答对迸星 + 光柱 | ✓ | — 卡随答对同批次卸载(实测:`correctId` 从未被赋真值) | — 教学期要克制 | ✓ |
| 水晶进度条 | ✓ | — 舞台 HUD 已占 | ✓ | ✓ |
| 连击大字 + 星尘计数 | ✓ | — 无此数据 | — | — |
| 连连看 炼金 + 爆点 | 炼金 ✓;**爆点仅非末对可见**(末对与 `onPass()` 同批次卸载) | 炼金 ✓;**爆点仅非末对可见**(末对与 `onPass()` 同批次卸载) | — 无连题 | — 无连题 |
| 听一听 不迸星(D9) | ✓ | ✓ | ✓ | ✓ |
| 景深(柔光 / 云 / 落影) | ✓ | — 舞台自备 | — **无天空** | — **无天空** |

> **勘误**:签字屏表格中「景深」一行原标 短教/冷启动 为 ✓,系**误标** —— 二者均为 `fixed inset-0` 的**全屏浮层**(`TeachOverlay.tsx:128` `bg-accent/10 backdrop-blur-sm`、`ColdStartWizard.tsx:114` `bg-surface/95 backdrop-blur-sm`),底下没有天空,加云是画蛇添足。本 spec 更正为「只有词课」。

> **勘误(2026-09-16,实施后据实测更正)**:①「答对迸星 + 光柱」的**千字谷跑章**列原标 `✓` **是事实错误** —— `src/features/qianzigu/scene-ui.tsx` 里 `correctId` **有状态、有传递,但 `setCorrectId` 只被赋过 `null`(换题复位),从未被赋真值**;答对分支是 `playSound('correct')` + `onPass()`,不设 `correctId`(对照 `WordLesson.tsx` 的 `setCorrectId(selectedId)`)。⇒ `Choice` 的 `juice = correctId === o.id && !quiet` 在千字谷**恒为 false**,答对永远不迸星、不上光柱;即便补上 `setCorrectId`,答对走 `onPass()` → 父级**同批次 re-key 卸载该卡**,迸星也来不及显示。②「连连看 炼金 + 爆点」的**词课 / 千字谷**两列原标 `✓` 不准确:**末对**的爆点看不见(末对成功即 `onPass()` → 同批次卸载),炼金不受影响。

**分档的实现方式**:分档全部落在**消费点是否渲染对应组件**,而非组件内部开关。`Choice`/`ListenChoice`/`MatchGame` 只新增**可选** prop(`quiet?: boolean` 供 D9),其余能力由消费点自行选装。

**D9 的落点**:`ListenChoice` 内部渲染 `Choice` 时传 `quiet` —— 四个消费点**零改**(它们只用到 `ListenChoice`,不知道 `quiet` 的存在)。`Choice` 收到 `quiet` 时不渲染 `SparkBurst`,光柱同理。

## 7 连连看:甲 + 丙

### 7.1 甲 · 炼金(状态层)

- 配对成功 → 左块转 `gold` 态:面变金、挂 ⭐ 角标、文字变**两行**(左选项文本 / 右选项 **emoji**)—— 两块的信息在同一块石头上合一,正是「声音层 → 形状层」的既有寓意。第二行取 emoji 而不是右选项文本/拼音:右列是**图卡**,是唯一带 `emoji` 字段的一列(左列只有 `text`)。
- 右块转 `slot` 态:虚线空位 + 内凹阴影,**不显示文字**(信息已并入金石,免去低对比度灰字)。
- 过渡:右块**缩小淡出** → 左块金色闪一下。**飞行合并(motion `layoutId`)为可选增强** —— 不稳则退化为上述方案,不影响交付(§10 R5)。

### 7.2 丙 · 爆点(事件层,与甲叠加)

- 配对成功瞬间:两块各向对方偏移 5px 并放大到 1.06 + 一圈**冲击波白环**从中心扩散 + 拟声词「**啪!**」(墨线艺术字,`aria-hidden`)。
- 全程 **≤450ms**,`motion` 驱动;无全屏位移、无震屏(D10)。
- 需要新增一个**瞬态** `burst: [string, string] | null` state + 定时清空 —— 与既有 `mismatch` 同一套模式(已有 `timerRef` 清理逻辑,复用)。

## 8 无障碍闸门(设计稿阶段即过,不留到测试)

| 项 | 要求 | 本轮落点 |
| --- | --- | --- |
| **色彩冗余** | 对错/状态**永不只靠颜色** | ✓/✗ 角标已有(上一轮);**新增态各自补形状**:`gold` → ⭐ 角标 + 两行结构;`slot` → 虚线边框 + 内凹(**非颜色**);爆点 → 拟声词字形 |
| 减动效 | `prefers-reduced-motion` 兜底 | 新动效**一律走 `motion`**(`App.tsx:249` `MotionConfig reducedMotion="user"` 自动继承),**禁写裸 CSS `animation`**。景深 / 光柱 / 晕托是**静态渐变**,不受影响 —— 减动效下画面不塌 |
| 闪光 | 频闪默认关 | 无频闪;爆点白环为**单次**扩散,非重复闪烁 |
| 震屏 | 须有「关」档 | **已砍**(D10),不引入 |
| 文字缩放 | 支持 2× | 石头高度用 `min-h` + `padding`,**禁固定 `height`**;晕托尺寸用 `em`(随 emoji 字号缩放);不设 `overflow: hidden` 截字 |
| 朗读 | 题干/选项可朗读 | **已具备**,逻辑不动 |
| 对比 | ≥ 4.5:1 | 金石文字用实测 token(7.75:1 / 5.37:1,§5);**新增态一律不用 `opacity` 压暗文字**(上一轮已因 `opacity` 吃过一次亏);`slot` 不显示文字 → 免谈 |

## 9 测试域影响

### 9.1 硬约束(实施前必读,与上一轮同源)

测试**全部靠 accessible name 定位选项**(`getByRole('button', { name: '太阳' })` 等)。本轮在选项按钮内部**新增更多节点**(晕托伪元素、迸星粒子、⭐/✗ 角标、爆点白环、拟声词),因此:

**任何新增的装饰节点必须 `aria-hidden="true"`**,否则会改变选项按钮的 accessible name → 大面积测试崩。

> 晕托是 `::before` 伪元素,不进 a11y 树,天然安全;迸星 / 白环 / 拟声词 / 角标是**真实节点**,必须显式标注。

### 9.3 新断言点

壳以 className 为主 → **不断言样式字符串**。断言锚:

- `stone.ts` 纯函数:六态(默认/选中/对/错/炼成/凹槽)的类名与角标字形
- `Stone.tsx`:`data-state` 与角标存在性(`button[data-state="gold"]` 含 ⭐ 且渲染两行文本)—— 色彩冗余的可测化
- `SparkBurst`:**`aria-hidden`** + 粒子数 ≤5;`quiet` 为真时**不渲染**
- `ProgressCrystals`:`total` / `current` → 点亮格数
- `MatchGame` 炼金:配对成功后左块 `data-state="gold"` 且**文本包含两侧内容**;右块 `data-state="slot"` 且**不含文本**
- `WordLesson`:断言顶栏渲染 `dust` 传入的星尘数。**`dust: number` 定为必传**(唯一真实调用方 `LessonEntry` 恒传;定为可选会留下「看着像功能其实没接线」的假绿路径),测试文件同步补传

### 9.4 全绿闸门

改完 `npm test` 须绿、`npm run lint` 0 error。⚠ **不写死基线数字**(仓库基线会随其它会话漂):用同一条命令在改动前后各跑一次、报告 delta。收口实测(2026-09-16)= **73 文件 / 485 用例全绿**,其中 1 文件 / 4 用例来自外来提交 `368a567`(不属于本计划)。
