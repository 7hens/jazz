# 🎮 星语群岛 · 完整游戏设计规范

> **版本**：v12.0 正式版
> **定位**：儿童语言与多元能力发展的沉浸式冒险游戏平台
> **适用年龄**：4-8岁
> **平台**：Web（移动端优先）
> **核心理念**：**孩子在“拯救世界”的过程中，自然而然地掌握语言与多元能力**

## 1. 产品概述

### 1.1 一句话定位

**星语群岛**是一款面向4-8岁儿童的沉浸式冒险学习游戏，孩子在五个主题世界中自由探索，通过拯救被“遗忘风暴”侵蚀的岛屿，学习汉语、英语、绘画、数学和音乐。

### 1.2 核心体验

```
孩子视角：
  “我是成长守护者，我在拯救星语群岛的每一个世界。”

家长视角：
  “孩子每天主动打开，玩得开心，而且真的在学。”

教育视角：
  “多通路编码 + 间隔重复 + 主动回忆 + 情感记忆 = 高效学习。”
```

### 1.3 五大设计原则

| 原则 | 说明 |
| ------ | ------ |
| **自由开放** | 五个世界随时可进，无解锁门槛 |
| **角色即世界** | 每个世界有一位专属向导，向导=学科专家 |
| **沉浸场景** | 全屏场景+两态切换（灰白/彩色），无“答题卡”感 |
| **科学学习** | 间隔重复+主动回忆+交错练习+多模态编码 |
| **家长可见** | 学习报告让家长看到进步，建立信任 |

## 3. 角色系统

### 3.1 角色总表

| 角色 | 领域 | 世界 | 性格 | 核心能力 |
| ------ | ------ | ------ | ------ | --------- |
| 🦊 灵灵 | 总向导 | 全群岛 | 活泼好奇 | 引导+鼓励+串联剧情 |
| 🐱 喵喵 | 英语 | 字母林 | 机灵爱冒险 | 字母拼读+单词 |
| 🐨 悠悠 | 绘画 | 万色谷 | 温柔创意 | 观察+创作 |
| 🐵 跳跳 | 数学 | 百数塔 | 好动爱数 | 数数+逻辑 |
| 🐰 音音 | 音乐 | 七音森 | 优雅敏感 | 节奏+音高 |

### 3.2 灵灵的特殊地位

- **总向导**：所有世界都出现，负责开场、串联、鼓励
- **世界专家**：每个世界的专属角色负责该世界的任务引导
- **切换逻辑**：进入某世界 → 灵灵介绍 → 世界专家接手 → 灵灵偶尔露脸

### 3.3 灵灵在千字谷

灵灵本身就是千字谷的向导（汉语是她的专长领域），因此她在千字谷同时承担总向导和世界专家两个角色。

## 4. 五个世界详设

### 4.1 🦊 千字谷（汉语：拼音+汉字）

**世界描述**：温暖的山谷，山壁上刻着汉字，空气中回荡着拼音的声音。

| 维度 | 设计 |
| ------ | ------ |
| 章节数 | 20章 |
| 每章词数 | 5词 |
| 总词汇 | 100词（核心词库） |
| 每章时长 | 10-12分钟 |
| 反派 | 静默（吃声音）+ 墨迹（涂字形） |
| 任务语法 | 听→辨→拼→读→用 |

**双层恢复机制**：

```
每词在千字谷有两层恢复：

第1层：声音恢复（拼音）
  → 找回 tài yáng 读音
  → 场景中出现声音

第2层：形状恢复（汉字）
  → 修复“太阳”笔画
  → 场景轮廓变清晰

两层完成 → 元素完全恢复发光
```

**千字谷任务模板（8个）**：

| 模板 | 技能 | 交互 |
| ------ | ------ | ------ |
| `pinyin-rune` | 拼音 | 符文选择 |
| `tone-melody` | 拼音 | 声调+音高可视化 |
| `listen-find` | 拼音 | 听音找物 |
| `hanzi-assemble` | 汉字 | 部件拖拽拼装 |
| `hanzi-match` | 汉字 | 图文配对 |
| `hanzi-stroke` | 汉字 | 笔画顺序 |
| `pinyin-hanzi-link` | 拼音+汉字 | 拼音汉字连线 |
| `scene-restore` | 综合 | 场景恢复 |

### 4.2 🐱 字母林（英语）

**世界描述**：神秘的魔法森林，树木上挂着字母，迷雾遮住了英文单词。

| 维度 | 设计 |
| ------ | ------ |
| 章节数 | 20章 |
| 每章词数 | 5词 |
| 总词汇 | 100词（与千字谷共享核心词库的英语维度） |
| 每章时长 | 8-10分钟 |
| 反派 | 迷雾（遮单词）+ 字母小偷 + 句序怪 |
| 任务语法 | 听→拼→译→说→用 |

**英语5层结构**：

```
L1 音素：26个字母音 → 字母音匹配
L2 拼读：CVC词 → 字母泡泡拼词
L3 高频词：the/is/I/you → 闪卡
L4 句型：I see a ___. → 句子拼装
L5 对话：简单对话 → 角色扮演
```

### 4.3 🐨 万色谷（绘画）

**世界描述**：色彩斑斓的山谷，像一幅水彩画，但颜色正在被擦除。

**核心体验**：孩子在纸上真实绘画，拍照导入，画作替换到场景中。

### 4.4 🐵 百数塔（数学）

## 5. 开放世界机制

### 5.1 自由进入

- 五个世界**全部开放**，无解锁门槛
- 孩子今天想学什么就学什么
- 每个世界内部章节可自由选择（建议顺序，不强制）
- 中途可退出，进度保留

### 5.2 每日推荐

```
每天第一次打开群岛总图：

灵灵：“今天想去哪里冒险？”

系统随机推荐一个世界（有光效标注）
推荐逻辑：
  - 默认随机（保持新鲜感）
  - 若某世界进度过低 → 温和推荐
  - 家长可设置“指定推荐世界”
```

### 5.3 均衡引导

```
万象树分支高度 = 各世界完成度

若某世界进度 < 其他世界平均进度的一半：
  灵灵温和提醒：“百数塔的小树苗才刚发芽呢～”

只提醒，不限制。
```

## 6. 任务引擎

### 6.1 任务生成流程

```
进入章节 → 场景灰白 → 灵灵开场 → 依次触发5个任务
→ 每个任务 = 一个词的学习（听音引子 → 核心互动 → 情境应用）
→ 5个任务完成 → 反派出现 → BOSS战（综合复习）→ 场景恢复彩色
```

### 6.2 每章结构（10-12分钟）

| 环节 | 时长 | 内容 |
| ------ | ------ | ------ |
| 开场 | 30秒 | 灵灵介绍本章危机 |
| 任务1 | 2分钟 | 名词学习（含绘画，可选） |
| 任务2 | 1.5分钟 | 动词学习 |
| 社交事件 | 1分钟 | 社交表达（固定环节） |
| 任务3 | 1.5分钟 | 形容词学习 |
| 任务4 | 1.5分钟 | 交际语学习 |
| 任务5 | 1.5分钟 | 综合挑战 |
| BOSS战 | 1分钟 | 混合5词的快速挑战 |
| 结局 | 30秒 | 场景恢复+结算+悬念 |

### 6.3 任务链结构

```
每个任务（一词）包含：

1️⃣ 听音引子（10-15秒）
   灵灵：“听！太阳的名字是... tài yáng”
   🔊 播放发音

2️⃣ 核心互动（1-1.5分钟）
   根据词类+技能选择交互模板
   主动回忆优先

3️⃣ 情境应用（15-30秒）
   元素恢复 → 场景变亮 → 灵灵鼓励
```

### 6.4 词类与互动映射

| 词类 | 互动模式 | 示例 |
| ------ | --------- | ------ |
| 名词 | 绘画+识别 | 画太阳→选拼音/汉字 |
| 动词 | TPR模仿+动画匹配 | 学“飞”→选飞的动物 |
| 形容词 | 情感匹配+修饰组合 | “开心”→选表情 |
| 交际语 | 对话+情境选择 | “谢谢”→选回应 |

### 6.5 失败恢复（三级救助）

```
第1次错误：
  选项变红 → 正确选项高亮 → 朗读答案 → 该题末尾重出

第2次错误（同一词）：
  自动降难度（选项4→2个）→ 灵灵帮助

第3次错误：
  灵灵示范正确答案 → 孩子跟着做 → 标记“需复习”

任何时候可跳过：
  灵灵说“好的，待会再来！”→ 任务标记“待完成”
```

## 8. 沉浸式视觉规范

### 8.1 六层视觉架构

```
第1层：背景层（CSS渐变+低透明度轮廓）
第2层：远景物（大Emoji/SVG，缓慢漂浮）
第3层：中景层（场景主体元素=孩子画作或Emoji）
第4层：近景层（花草装饰，轻微摆动）
第5层：UI层（灵灵/按钮/提示，浮在场景上）
第6层：特效层（粒子/光晕/转场遮罩）
```

### 8.2 场景两态切换

```css
/* 灰白状态 */
.scene-desaturated {

  transition: filter 0.8s ease;
}

/* 恢复状态 */
.scene-restored {
  filter: grayscale(0%) brightness(1);
  transition: filter 1.5s ease;
}
```
