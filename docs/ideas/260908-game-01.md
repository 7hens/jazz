# 🦊 千字谷 · 家庭版设计规范

> **版本**：v2.0 家庭版
> **使用者**：自己的孩子
> **核心变化**：去掉商业合规/家长端/多设备等负担，聚焦“让孩子玩得开心、学得有效”
> **原则**：极简、温暖、有爱

## 1. 产品定位

### 1.1 一句话

**给自家孩子的汉语学习冒险游戏，孩子拯救千字谷，顺便学会拼音和汉字。**

### 1.2 与商业版的区别

| 维度 | 商业版 | 家庭版 |
| ------ | -------- | -------- |
| 用户量 | 海量 | 1-2个孩子 |
| 合规 | COPPA/隐私政策 | 不需要 |
| 家长端 | 完整报告系统 | 简单进度查看即可 |
| 年龄适配 | 4-8岁全段 | 按自家孩子年龄定制 |
| 内容 | 标准100词 | 可加入孩子喜欢的词 |
| 语音 | Web Speech | Web Speech + **可录家长自己的声音** |
| 开发周期 | 10周 | 4-6周核心可玩 |
| 技术架构 | 完整前后端 | 可纯本地，零后端 |

## 2. 核心体验流程

### 2.1 完整循环

```
打开游戏
  ↓
千字谷地图（已完成章节彩色，未完成灰白）
  ↓
选择章节 → 灰白场景 → 灵灵语音开场
  ↓
任务1：听声音 → 画画（可选）→ 拼拼音 → 拼汉字 → 太阳复活
  ↓
任务2-4：快速任务，每个1.5分钟
  ↓
社交事件：灵灵语音讲故事，孩子语音选择回应
  ↓
BOSS战：快速混合挑战
  ↓
场景恢复彩色 → 庆祝 → 下一章悬念（语音）
```

### 2.2 全流程语音（核心）

**所有文字都有语音，孩子不需要认字。**

| 内容 | 语音方式 |
| ------ | --------- |
| 灵灵说话 | Web Speech 自动朗读 |
| 故事叙述 | Web Speech 朗读 |
| 选项按钮 | 自动逐个朗读，孩子听后选择 |
| 反馈鼓励 | 语音+文字同步 |
| 任务引导 | 灵灵直接说，不显示长文字 |
| 章节标题 | 语音读出“第3章：月亮哭了” |

**增强（家庭版特有）**：

```
家长录音功能：
  家长可以录制自己的声音替换Web Speech
  例如：
    灵灵的台词 → 妈妈录“太棒了！你做到了！”
    静默的台词 → 爸爸录“声音真好吃...”

  效果：孩子听到的是爸爸妈妈的声音在讲故事
  成本：约20条核心语音，每条2-3秒
  实现：MediaRecorder API + LocalStorage 存储
```

**这是家庭版独有的温暖设计，商业版做不了（涉及版权和录制成本）。**

## 3. 学习科学（保留核心）

### 3.1 每词学习循环

```
听音引子（10秒）→ 创作锚定（可选）→ 主动回忆（核心）→ 情境应用
```

### 3.2 主动回忆 > 被动再认

```
被动（弱）：
  显示☀️ → 选拼音

主动（强）：
  播放 tài yáng → 孩子在场景中找到太阳
  显示 _ài y_ng → 补全拼音
  显示 太_ → 补全汉字
```

### 3.3 间隔重复

```
学完当天 → 即时复习（BOSS战）
+1天 → 快速回顾（3题）
+2-3天 → 场景回顾
+7天 → 场景回顾
+14天 → 场景回顾
```

### 3.4 脚手架递减

| 次数 | 提示 | 灵灵说 |
| ------ | ------ | -------- |
| 首次 | 完整选项 | “我来帮你！” |
| 复习1 | 填空 | “你更厉害了！” |
| 复习2 | 无提示 | “自己来！” |
| 复习3 | 主动回忆 | “凭记忆说！” |

## 4. 失败与情绪安全

### 4.1 三级救助

```
第1次错：温和提示，正确选项高亮
第2次错：选项减半，灵灵帮助
第3次错：灵灵直接示范，标记“需复习”
任何时候：可跳过，不惩罚，下次优先
```

### 4.2 整章失败恢复

```
BOSS战连续失败：
  已完成的5个任务全部保留
  场景显示“已恢复大部分，只差最后一步”
  下次进入直接挑战BOSS
  灵灵：“已经救了很多了！下次再来！”
  给“勇气徽章”安慰
```

### 4.3 自然断点

```
每个任务完成后：
  灵灵：“想继续就点这里，想休息就明天再来！”
  进度自动保存
  随时可退出
```

## 5. 趣味性系统

### 5.1 保留

- 连击系统（3/5/8/10/15分级特效）
- 随机夸奖（15条够用）
- 撒花动画
- 灵灵情境回应
- 隐藏成就（5个够用）

### 5.2 幽默时刻（家庭版重点）

```
每章至少1个幽默点：

静默不小心吃掉自己的声音：
  “呃...呃...（嘴巴一张一合）”
  灵灵：“哈哈！你说不出话了吧！”
  孩子帮它找回声音
  静默：“谢谢...（小声）”

墨迹画太阳画成了鸡蛋：
  “这不是太阳...这是早餐...”
  灵灵：“哈哈哈哈！”
```

### 5.3 孩子专属词库（家庭版特有）

```
可以加入孩子生活中的人/物：

  妈妈、爸爸、宝宝的名字
  家里宠物的名字
  孩子最喜欢的玩具
  每天吃的食物

例如：
  第6章加入“妈妈”（mā ma / 妈妈 / 妈+妈字族）
  孩子学到“妈妈”时，场景中出现妈妈的形象
  情感连接极强
```

**实现**：词库JSON中标记 `isPersonal: true`，可随时添加。约10个个性化词。

## 6. 内容设计

### 6.1 章节规划（20章）

| 区域 | 章节 | 主题 | 核心词 |
| ------ | ------ | ------ | -------- |
| 天空 | 1-5 | 太阳/月亮/星星/云/彩虹 | 25词 |
| 大地 | 6-10 | 山/树/花/草/叶子 | 25词 |
| 家园 | 11-15 | 房子/门/窗/床/椅子 | 25词 |
| 情感 | 16-20 | 开心/难过/生气/害怕/爱 | 25词 |
| 个性化 | 穿插 | 妈妈/爸爸/宠物名... | 10词 |

### 6.2 每章结构（8-11分钟）

| 环节 | 时长 | 内容 |
| ------ | ------ | ------ |
| 语音开场 | 30秒 | 灵灵讲故事引入 |
| 任务1（名词） | 2-3分钟 | 听→画→拼→恢复 |
| 任务2（动词） | 1.5分钟 | 听→选→恢复 |
| 社交事件 | 1分钟 | 语音对话，后果式选择 |
| 任务3（形容词） | 1.5分钟 | 听→选→恢复 |
| 任务4（交际语） | 1.5分钟 | 听→说→恢复 |
| BOSS战 | 1.5分钟 | 混合复习 |
| 结局+悬念 | 30秒 | 语音庆祝+预告 |

### 6.3 词汇总量

```
核心词：100词
个性化词：10-20词
总计：110-120词

对孩子来说足够建立基础汉字和拼音意识
后续可无限扩充
```

## 11. 总结

```
家庭版的千字谷：

  不是为了“上线赚钱”
  是为了“我的孩子”

  不需要考虑合规、隐私、多设备、排行榜
  只需要考虑：
    我的孩子今天愿意打开吗？
    我的孩子玩的时候开心吗？
    我的孩子真的学会了什么吗？
    我的孩子学完后更爱学习了吗？

  最好的设计：
    全语音（不认字也能玩）
    有幽默（笑出声的那种）
    有爱（爸爸妈妈的声音、自己的名字）
    能坚持（有断点，不惩罚，有惊喜）

  核心循环：
    打开 → 听到灵灵说话 → 拯救一个词 → 看到画面变亮
    → 灵灵夸我 → 想知道下一章 → 明天再来
```
