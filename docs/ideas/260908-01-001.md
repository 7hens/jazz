# 🦊 千字谷 · 第1章《太阳的求救》完整设计规范

> **章节主题**：天空区·第一束光
> **核心词汇**：太阳（名词）/ 升起（动词）/ 亮（形容词）/ 早上好（交际语）/ 星星（名词）
> **章节时长**：10-12分钟（含自然断点）
> **核心情感**：从“灰暗的担忧”到“第一束光的喜悦”

## 1. 章节目标

### 1.1 学习目标

| 词 | 拼音 | 汉字 | 词类 | 学习重点 |
| ----- | ------ | ------ | ------ | --------- |
| 太阳 | tài yáng | 太阳 | 名词 | 声母t/y、韵母ai/ang、字“太”“阳” |
| 升起 | shēng qǐ | 升起 | 动词 | 声母sh/q、韵母eng/i、TPR动作 |
| 亮 | liàng | 亮 | 形容词 | 声母l、韵母iang、三声调 |
| 早上好 | zǎo shang hǎo | 早上好 | 交际语 | 日常问候、三声调 |
| 星星 | xīng xing | 星星 | 名词 | 声母x、韵母ing、轻声 |

### 1.2 情感目标

- 建立“我能帮助别人”的自信
- 体验从灰暗到光明的希望感
- 与灵灵建立伙伴关系
- 对“静默”产生好奇（不恐惧）

## 4. 完整对话脚本

### 4.1 开场（30秒）

```
【场景：灰白的天空区域，太阳暗淡，月亮流泪，村庄寂静】

🦊 灵灵（从飞艇跳下，环顾四周）：
  “千字谷到了！但是...好暗啊...”

（灵灵抬头看太阳）

🦊 灵灵（走近太阳，轻声）：
  “太阳...你怎么了？”

☀️ 太阳（灰白，微弱颤抖）：
  “救...救救我...我的声音...被吃掉了...”
  （声音断断续续，有回音效果）

🦊 灵灵（转身面对孩子，语速稍快）：
  “太阳在求救！它的声音被静默吃掉了！”
  “它的形状也被墨迹涂花了！”
  “你是成长守护者，你能帮帮它！”

（灵灵伸出小爪子，等待孩子回应）

💬 界面显示两个按钮：
  [🌟 我来帮忙！]  [❓ 怎么了？]

如果孩子选择“❓ 怎么了？”：
  灵灵重新解释：“太阳发不出声音了，字也被弄花了！我们要救它！”
  然后自动进入任务1
```

### 4.2 任务1：拯救太阳（3分钟）

**第1步：听音引子（15秒）**

```
🦊 灵灵（靠近孩子，小声）：
  “听！这是太阳的声音...”

🔊 [播放 tài yáng，缓慢，清晰]

🦊 灵灵：
  “tài yáng！记住了吗？”
  “太阳的声音是 tài yáng！”

🔊 [再听一次] 按钮浮现
```

**第2步：创作锚定（1.5分钟）**

```
🦊 灵灵：
  “太阳的样子也模糊了...”
  “你来画一个太阳吧！”

📝 画面中央出现纸张卡片：
  “画一个圆”
  “再加上光线”

🦊 灵灵：
  “画好了就拍照给我看！”

[📷 拍照导入] 按钮

→ 孩子拍照 → 自动抠图 → 预览确认

🦊 灵灵（看到画，开心地跳）：
  “哇！这是你画的太阳！”
  “好漂亮！”

→ 孩子的画出现在场景中太阳的位置
→ 画作有微光闪烁
```

**第3步：拼音恢复（45秒）**

```
🦊 灵灵：
  “太阳的名字是什么？”
  “找到正确的读音！”

【空中浮现3个发光符文，自动逐个朗读】

  ┌─────────┐  ┌─────────┐  ┌─────────┐
  │ tài yáng│  │ tái yáng│  │ tài yàng│
  │  🔊     │  │  🔊     │  │  🔊     │
  └─────────┘  └─────────┘  └─────────┘

（符文自动依次朗读，每次间隔0.5秒）

孩子点击正确的 → 符文发光飞向太阳 → 太阳发出“嗡”的震动声

❌ 如果选错：
  符文变灰，灵灵说：“再听一次，tài yáng！”
  → 重新朗读后再次选择
```

**第4步：汉字恢复（45秒）**

```
🦊 灵灵：
  “声音回来了！但字还看不清...”

【太阳下方散落汉字部件】

  [太] [阳]
  [大] [丶] [阝] [日]

🦊 灵灵：
  “把‘太阳’两个字拼出来！”

（孩子拖拽部件组合）

✅ 拼对瞬间：
  汉字发光 → 飞向太阳 → 太阳轮廓变清晰
  ✨ 全屏小闪光（0.3秒）

❌ 拼错：
  部件弹回原位
  灵灵：“试试看，‘太’字是‘大’加一点！”
```

**第5步：情境应用（15秒）**

```
☀️ 太阳完全恢复！发出金色光芒！
（孩子的画作 + 光芒效果）

🦊 灵灵（跳起来）：
  “太棒了！太阳复活了！”

🐰 居民（从村口抬头）：
  “有光了...！谢谢你！”

🌅 画面右上角变亮，阳光洒下
```

**【自然断点】**

```
🦊 灵灵：
  “想继续吗？还是休息一下？”

[继续拯救] [明天再来]
```

### 4.3 任务2：教会太阳升起（1.5分钟）

```
🦊 灵灵（抬头看太阳）：
  “太阳虽然活了，但它还不会升起...”
  “我们教它‘升起’！”

第1步：听音（15秒）
  🔊 [播放 shēng qǐ]
  🦊 灵灵：“shēng qǐ！升起！”

第2步：TPR模仿（30秒）
  🦊 灵灵（慢慢从蹲下到站起来）：
    “看！这就是‘升起’！”
    “你也来做‘升起’的动作！”

  （画面中灵灵演示，孩子跟着做，不需要识别）

  [我做好了！] 按钮

第3步：动画匹配（45秒）
  🦊 灵灵：“哪个小动物在‘升起’？”

  【4个小动物做不同动作】
  🐦 飞    🐱 睡    ☀️ 升起    🐰 跳

  （每个动物旁有🔊按钮，点击播放“飞”“睡”“升起”“跳”）

  孩子选择 ☀️ → 太阳慢慢升起来

❌ 选错：
  灵灵：“这是‘跳’哦！再找找‘升起’！”

第4步：情境应用（15秒）
  ☀️ 太阳升到天空最高处
  🦊 灵灵：“太阳升起来了！天空变亮了！”
```

### 4.4 社交事件：安慰月亮（1分钟）

```
【场景：太阳恢复了，但月亮还在流泪】

🦊 灵灵（轻轻）：
  “咦...月亮在哭...”

🌙 月亮（抽泣）：
  “大家都喜欢太阳...没有人喜欢我...”
  “白天有太阳...晚上只有我...好孤单...”

【选项逐个弹出，自动朗读】

选项A弹出：
  🔊 “你哭起来真难看。”
  [选这个] [听下一个]

选项B弹出：
  🔊 “我也喜欢你！你照亮了夜晚！”
  [选这个] [听下一个]

选项C弹出：
  🔊 （不说话，走开）
  [选这个] [听下一个]

─── 如果选A ───
🌙 月亮哭得更伤心了...
🦊 灵灵：“月亮更难过了...我们想想怎么安慰它？”
→ 重新弹出选项（提示：说一些温暖的话）

─── 如果选C ───
🌙 月亮继续哭...
🦊 灵灵：“月亮还在哭...我们回去看看它？”
→ 重新弹出选项

─── 如果选B ───
🌙 月亮（停止哭泣，眼睛亮起来）：
  “真的吗？...谢谢你！”
  “我每天晚上都会为你照亮的！”

✨ 月亮发光，柔和的月光洒下

🦊 灵灵（感动）：
  “你学会了安慰别人！”
  “月亮开心了！”
```

## 5. 社交事件详细设计

### 5.1 选项逐个弹出机制

```typescript
interface SocialOption {
  id: 'a' | 'b' | 'c';
  text: string;
  emoji: string;
  consequence: 'good' | 'bad' | 'neutral';
  response: string;  // 月亮/灵灵的回应
}

const moonComfortOptions: SocialOption[] = [
  {
    id: 'a',
    text: '你哭起来真难看。',
    emoji: '😠',
    consequence: 'bad',
    response: '月亮哭得更伤心了...',
  },
  {
    id: 'b',
    text: '我也喜欢你！你照亮了夜晚！',
    emoji: '💕',
    consequence: 'good',
    response: '月亮笑了！',
  },
  {
    id: 'c',

    emoji: '🚶',
    consequence: 'neutral',

  },

```

### 5.2 后果式循环

```
选择 → 看到后果 → 如果不理想 → 灵灵引导 → 重新选择
     → 如果理想 → 月亮开心 → 继续

关键：不强制“答对”，而是让孩子看到每个选择的不同后果
      最终都导向“月亮被安慰”的结局
      但孩子体验到了“不同的话有不同的效果”
```

## 6. 全语音实现规范

### 6.2 语音参数

```typescript
const SPEECH_CONFIG = {
  lingling: { rate: 0.75, pitch: 1.2, lang: 'zh-CN' },
  sun: { rate: 0.65, pitch: 0.8, lang: 'zh-CN' },
  moon: { rate: 0.7, pitch: 1.0, lang: 'zh-CN' },
  jingmo: { rate: 0.6, pitch: 0.5, lang: 'zh-CN' },
  narrator: { rate: 0.8, pitch: 1.0, lang: 'zh-CN' },
};

function speakRole(text: string, role: keyof typeof SPEECH_CONFIG) {
  const config = SPEECH_CONFIG[role];
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = config.lang;
  utterance.rate = config.rate;
  utterance.pitch = config.pitch;
  speechSynthesis.speak(utterance);
}
```

## 7. 交互细节

### 7.1 拼音符文选择

```
3个符文在空中排列，每个符文：
  - 半透明发光
  - 自动依次朗读
  - 点击后放大+朗读
  - 正确：飞向太阳
  - 错误：变灰+重新朗读
```

### 7.2 汉字拼装

```
部件散落在地面，每个部件：
  - 大尺寸（≥64px）
  - 可拖拽
  - 放到正确位置：吸合+发光
  - 放到错误位置：弹回
```

### 7.3 场景元素点击

```
场景中的元素（太阳/月亮/星星）：
  - 待拯救状态：抖动+灰白
  - 拯救中：发光+脉冲
  - 已恢复：发光+微笑+微动画
```

```
□ 孩子不需要认字，全程语音引导

□ 悬念引发孩子期待下一章
```
