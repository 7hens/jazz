## 1 前提与主题命题

- **logline(苏灵灵视角)**:苏灵灵是千字谷镇跑得最快、最爱帮忙的小狐狸;她在路上撞见把什么都忘光了的徐万年爷爷,于是一个名字一个名字地,帮他把这一天找回来。
- **主题命题(2026-09-10 定稿)**:「**叫得出名字,就有人记得你**」—— 命名即存在。全篇由正反例演出,**角色不得直接念出**。
- **情感目标**:建立「我能帮助别人」的自信 · 体验「叫不出名字就办不成」的日常窘迫与恢复的畅快 · 与苏灵灵建立伙伴关系 · 对藏名字的吴铭**好奇而非恐惧**。
- **正反例锚点**:徐万年得回「房子」二字才想起家在哪(t1-shape)✓;吴铭藏尽别人的名字,自己却没人叫对过一次(轻线,后段兑现)✓。
- **主角 = 苏灵灵**;故事围绕她展开(她的事、她的镇子、她的热心)。**玩家 = 无名搭档**,**不给任何背景设定**(无「搬来」、无「守护者」、无「家」),不出立绘、无台词。苏灵灵对「你」说话;剧情不是「你」的故事,是苏灵灵的故事。

## 3 角色台账

> **为什么是台账不是百科**:百科只堆设定,是「设定倾泻」的温床;台账每字段必须**有演出落点**(哪一场演出它),写不出落点的字段不许存在。
> **影子字段纪律**:每栏必须有演出落点;写不出落点的栏 = 删栏或补戏。字段空着 = 欠账,和伏笔一样要还。**吴铭的「伤口 / 弧光终点」明标【待全篇框架定】,不编** —— 但它同时是**欠账**,写全篇框架时必须还。
> **一页卡是全季角色 canon 的唯一权威位置**;spec §4.5 只留指针,视觉侧(`game-assets.md`)引用不复制。

### 3.2 跨角色规则(机制约定,不属任何单卡)

- **人称即分工(2026-09-10 定)**:旁白 = 第三人称叙述 / 过场 / 结果陈述;角色泡 = 指令 / 提问 / 情绪 / 交际。
- **旁白框视觉最弱**:顶部虚线小字(`text-sm text-ink-2`)→ **指令与高潮时刻必须留在角色泡里**,不派给旁白。
- **遮名测试判据**:遮住角色名仍能辨出说话者 = 通过。**教学句豁免**:教学场面单说话者、读音须干净,故按设计用中性指令腔 —— 遮名测试只对剧情场面生效。
- **功能位角色不该有弧光**:主角的成长不可被抢。反派必须受**同一套世界规则**约束(吴铭也只能被「叫对名字」触动,不能破例)。
- **埋了必收、收前必埋**:见 §6。空头悬念比没有悬念更伤。

**命名纪律**(儿童靠自己听认角色,硬约束):

- 姓 + 名;新名与**同章已登场角色**声母或字形不得过近。

- 名称不得与词库 100 词任一读音重合。

## 4 章节结构契约(ch1 现态)

- **场景序**:`open → t1-sound → t1-shape → br1 → t2-sound → t2-shape → br2 → social-pixiaonao → br3 → t3-sound → t3-shape → t4-sound → t4-shape → t5-sound → t5-shape → boss → ending → settle`(共 **18 场景**:10 task / 3 break / dialogue·social·boss·ending·settle 各 1;断点恰 3 个)。
- **每章结构**:5 词 × 双层恢复 × `minCorrect 2` + 3 断点 + 1 社交事件 + 1 BOSS + ending + settle。
- ★ **词即剧情道具(本作最强结构资产;守则)**:词序 = 因果链 —— **房子(13)** 想起家在哪 → **门(7)** 忘了推还是拉 → **钥匙(14)** 叫不出名就摸不着 → **窗户(8)** 闷得慌要透气 → **台灯(19)** 天黑点灯,这一天成了。**先排因果链 → 再选词 → 最后写台词**;禁止为迁就词表打乱因果。
- **BOSS 叙事降级**:叙事上是一场「闹剧 / 难关」(徐万年的记忆搅成一团,5 个名字一个个叫回来),**结构位不动**。
- **叙事形态**:线性教育主线 + 局部选择(社交片段),**非多结局叙事**;BOSS 的 win/lose 与社交的 bad/neutral 都是**重试分支**。社交 3 选项仅 1 个推进(其余回 `loop`)属**有意设计**(教育性重试,儿童向)。
- **台词硬线**(仓库内,严于技能通用 30 字):单句推荐 **≤18 汉字**、硬线 **≤20**,超 20 必按意群拆 —— `ch1-script.test.ts` 守卫。
