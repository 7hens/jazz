## 1 逐幕分镜表(18 幕)

字段:`舞台数据` = `ch1.ts` 的 `stage` 实况 · `交互` = 玩家实际动作 · `演出钩子` = 该幕要传达的事。

### 1.1 开场

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `open` | 立人物 + 立「爱忘事」的人设 | 缺省(`dawn`,镇上早晨) | 逐行点击推进(11 行) | 旁白冷开场 → 苏灵灵自我介绍 → 撞见徐万年站在道中卡壳 |

- **镜头**:徐万年**不是天空体**,与苏灵灵同在地面行(本章无 `sky`)。⚠「爱忘事」是**人物喜剧**,不是世界观规则,演出要憨、要好笑,不可怖。
- **转场出**:末行结束由顶层整屏接管 → 进 `t1-sound`。

### 1.2 词 1「房子」(13)

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `t1-sound` | 声音层恢复 | 缺省 | intro 整屏 → 2 题 | 徐万年说不出家在哪;叫回「房子」 |
| `t1-shape` | 形状层恢复 | 缺省 | 2 题 → `onDone` 3 行 | **想起家在哪 = 第一个小高潮**(`fraction` 前进一档) |

- **题序**(`makeStepQuestions`,`engine.ts`):首题恒 `choice`;次题 `pinyin` 技能下 = 50% `listen-choice` / 50% `choice`。`minCorrect: 2`。
- **答题反馈**:每题 **2 次机会**;答对立即放行并重挂下一题;第 1 次错标记错项,第 2 次错进 `reveal` 揭示答案。
- ⚠ `t1-shape.onDone` 含**自然断点前的休息提示**(BreakScene 无台词槽,并入上一幕收尾)—— 文案归 `ch1.ts`。

### 1.3 词 2「门」(7)

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `t2-sound` | 声音层 | 缺省 | intro 整屏 → 2 题 | 站在家门口,忘了这叫「门」,推也推不动 |
| `t2-shape` | 形状层 | 缺省 | 2 题 → `onDone` 2 行 | 认出「门」→ 知道该往里推;苏灵灵点破刚才拉反了 |

- **演出要点**:`onDone` 是**同一拍的两半** —— 徐万年先认出、苏灵灵补一句调侃。先认后笑,不可换。

### 1.4 社交事件:皮小闹冒失撞人

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `social-pixiaonao` | 后果式选择 | `cast:['lingling','pixiaonao']`(缺省 `dawn`) | 3 选项 → good / 非 good | 皮小闹撞了徐爷爷;玩家的**选择有代价** |

- **决策流**:

```text
皮小闹冒失撞人(lines;旁白一记撞击声标 mood:scary)
      ↓
   3 选项
              ├─ 选 b(good)  → onGood(皮小闹道谢 + 苏灵灵肯定,
              │                 皮小闹标 mood:happy) → br3
              └─ 选 a/c(非good) → loop 重弹(苏灵灵引导) ─┐
                     ↑___________________________________|
```

- **现状**:非 good **不给独立演出** —— 仅回 `loop` 重弹苏灵灵引导词。这是**有意的教育性重试**(儿童向,不惩罚);「给 bad/neutral 一次性独特演出后仍引回正轨」列为候选升级,见 `docs/PLAN.md` 想法池,**未立项**。
- **视觉**:本章社交戏在白天(`dawn`),**不是夜戏**;全场唯一真夜戏是 `t5` 台灯两幕(`atmosphere:'night'`)。皮小闹情绪由 `mood` 承载(`scary` → `happy`)。

### 1.5 词 3「钥匙」(14) / 词 4「窗户」(8) / 词 5「台灯」(19)

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `t3-sound` | 声音层 | 缺省 | intro 整屏 → 2 题 | 门锁着;钥匙在口袋,叫不出名就摸不着 |
| `t3-shape` | 形状层 | 缺省 | 2 题 → `onDone` 2 行 | 认出「钥匙」→ 到手 → 旁白一句收束这一场(门开) |
| `t4-sound` | 声音层 | 缺省 | intro 整屏 → 2 题 | 进屋闷得慌,想要个通风的口子 |
| `t4-shape` | 形状层 | 缺省 | 2 题 → `onDone` 2 行 | 叫回「窗户」→ 风进来;皮小闹补一句——屋里亮了 |
| `t5-sound` | 声音层 | `atmosphere:'night'` | intro 整屏 → 2 题 | 天黑了;叫回「台灯」 |
| `t5-shape` | 形状层 | `atmosphere:'night'` | 2 题 → `onDone` 2 行 | 灯亮 → 屋子暖起来 = **这一天成了** |

- **题序**(`hanzi` 技能):首题恒 `choice`;次题 = 50% `match` / 50% `choice`。`match` = `MatchGame` 整组配对,**配对成功即通过(`attempt` 恒 1,无二次机会)** —— 与其余题型的两次机会**不一致,属既有行为**。
- **布景状态**:`t5` 两幕标 `atmosphere:'night'`,真夜幕**隐去布景太阳**(`StageSky` 的 `HIDES_SUN`);`fraction` 随恢复进度推进世界回春,**无太阳分档**(太阳为固定单态布景,见 `game-visual.md`)。

### 1.6 BOSS:徐爷爷的记忆闹剧

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `boss` | 交错考核 | 缺省(boss 默认 `dark`) | intro 3 行 → **5 题交错** → win / lose | 徐万年把 5 个名字搅成一团;一个个叫回来 |

- **题池**:全章 5 词;每题取 `makeStepQuestions(word, skill)[0]`(即 `choice`)。
- **失败阈值**:`maxWrong: 3`、`questionCount: 5`。win 走 `win` 行(徐万年全想起,标 `mood:happy` + 苏灵灵收束);lose 走 `lose` 行(苏灵灵宽慰、明天再来)。
- **演出要点**:叙事上是「一场闹剧 / 一个难关」,**没有挑战者**,结构位不动(bible §4)。win 的补齐 = 本章高潮,不得用旁白说教。
- ⚠ 加钩子台词时**先 grep 全章去重**(历史上有过 `win` 与 `settle` 逐字重复)。

### 1.7 结局与结算

| id | 功能 | 舞台数据 | 交互 | 演出钩子 |
| --- | --- | --- | --- | --- |
| `ending` | 全彩 / 暖灯 | 缺省(`day`) | 逐行点击(4 行) | 灯亮着 + 皮小闹咋呼 + 苏灵灵总括;⚠ **白闪未接 `celebrate`(现死)** |
| `settle` | 结算 + 悬念 | 缺省(`day`) | `SettleCard` | 苏灵灵总括 → 徐万年忽然连一件天天都记得的事也忘了 → **轻线痕迹**,不解释(5 行) |

- **`settle` 是唯一带「钩子」职责的幕**:每新增一句「还有下次」必须同时登记回收位(bible §6)。ch1 已埋项 = settle 里徐万年那句反常的失忆怪话(不解释)。

## 2 章节级交互流

```text
open → t1-sound → t1-shape → br1
                               ↓
              t2-sound → t2-shape → br2
                                     ↓
                        social-pixiaonao → br3
                                            ↓
   t3-sound → t3-shape → t4-sound → t4-shape → t5-sound → t5-shape → boss → ending → settle

br1 / br2 / br3 另有「明天再来」出口 → 落库并回章节地图
```

- **断点(`break`)**:`BreakScene` 提供「继续」/「明天再来」;后者落库并回章节地图。3 处断点位置不可增删(结构契约,bible §4)。
- **叙事形态**:线性主线 + **局部选择**(仅 social),**非多结局**。BOSS 的 win/lose 与 social 的 bad/neutral 都是**重试分支**,不构成结局分支。
