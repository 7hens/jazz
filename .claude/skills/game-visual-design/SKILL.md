# 游戏视觉设计(全屏漫画演出 + AI 素材)

## 定位与原则

目标 = 无传统分格、全屏沉浸的「动态画册/交互式电影」视觉:模拟纸张/印刷网点/胶片等**材质感**;靠布局、色彩、景深建**叙事层级**引导视线;静帧嵌**微动效蓝图**让画面「呼吸」。素材配方与流程细节在 `references/blueprint.md`(设计流程与 UI 蓝图)、`references/ai-materials.md`(AI 提示词工程与合成)。

协作定位:**AI = 首席画师**(产角色立绘/场景/动态片段);设计师与 Claude 专注视觉统合、构图框定、UI 质感。素材产出 = 写合格提示词 → **人工在外部 AI 工具跑**(Midjourney/Runway/Kling…)→ 抠图校准 → 回填目标项目的素材/视觉映射点。Claude 不在组件内联临时素材或死样式绕过既有视觉接缝。

> **数值权威(防漂移)**:本 SKILL 的表格与红线、以及 `game-pipeline/references/checklists.md` 的速查表,都只是**速查**;文案密度 / 对比 / 出血安全区 / 性能预算的细则归 `references/blueprint.md`,素材动作数值(呼吸幅 / 待机首尾差 / 循环时长)归 `references/ai-materials.md` —— 冲突时**以 references 为准**,别在三处各改一半。

## 交付物(缺一即未完成)

| 交付物 | 内容 | 落在哪 |
| --- | --- | --- |
| 视觉设计蓝图 | 情绪色盘 → 三层构图 → UI 蓝图 → 材质/动效 | 项目设计文档 |
| **素材 prompt 档** | 每角色一**锚点块(冻结)**+ 立绘/待机 prompt + 固定 seed;布景元素 + 氛围档 + 情绪符号;**质检闸门 + 回填映射** | **项目设计文档**(不是技能) |
| **角色设定表** | 每角色**3/4 侧视图**(单一固定转角、全身入镜)+ **表情集**(6–9 格)+ 道具设定 + **配色板(hex)** | 项目设计文档(锚点权威的展开) |
| **无障碍清单** | 减动效开关 · 色彩冗余(形状/图标)· 文字缩放 · 朗读兜底 · 闪光默认关 | 项目设计文档 + 代码接缝 |
| 回填映射表 | 每类素材 → 项目哪一处代码/资产点,及**前置立项条件** | 项目设计文档 |

⚠ **角色设定表 ≠ 一张立绘**:锚点块只描述"长什么样",**3/4 侧视 + 表情集**才定义"上镜时、带情绪时长什么样"。**没写进设定表的东西,AI 每张都会自己发明** —— 刘海分缝、衣领形状、配饰位置,事后必不一致。
> 只做**一个固定转角**(3/4 侧),不做正/侧/背转面 —— 全屏演出里角色极少以正背示人,转面成本不划算。

⚠ **素材 prompt 档是本技能最常被漏掉的交付物** —— 只给配方不给成品档,项目就会:①`docs/` 里 0 个素材档;②锚点被塞进技能;③下游文档引用一个**根本不存在**的文件。产出它,并让所有下游**只放指针**。

## 何时用(触发)

- 设计/补编剧情游戏 scene 视觉:布景构图、氛围色盘、角色视觉/站位、对白演出。
- 视觉语言增强:气泡情绪造型(呐喊锯齿/思考云泡/字号)、拟声词艺术字、镜头语言、材质覆盖、转场。
- 需产 AI 素材提示词(立绘/背景/动画待机/镜头运动)给人外跑。
- 情绪色盘、对白/旁白字级、站队/朝向等视觉决策拿不准时。

## 设计流程(先想清再动手)

1. **提取核心视觉关键词** 3-4 个(例:童话+旧漫画网点+高反差),作情绪板主轴。
2. **定情绪色盘**:「情绪 → 色彩」映射(例:平和对话→青蓝;爆发→橙红)。⚠ 抽象色盘须**转译**成目标项目现成的情绪载体(token/边框色/氛围渐变),勿照搬直译。
3. **三层静态构图**:背景层(100%,暗角遮罩防抢镜)/ 角色层(安全区不遮文)/ 前景交互层(底/侧固定:对话框、选项、进度)。
4. **核心 UI 蓝图**:气泡 3 变体(圆泡对白 / 锯齿独白 / 尖泡怒吼·旁白,尾指向明)、Type Ramp 6 级(H1 拟声 / H2 角色名 / Body 对白 / Caption 旁白 / Button / Label)、按钮 3 态(默认/悬停/按下)。
5. **AI 构图适配**:留白蒙版(标 AI 背景图须纯色/模糊区)+ 角色站位卡(3-4 固定构图模板,UI 框线对齐视线方向)。
6. **材质与动效蓝图**:顶层网点/噪点统一质感(克制,3-5%+轻微);转场关键帧(擦除线/白闪)标方向与耗时。
7. **同步定无障碍基线**:色彩冗余(不只靠色)/ 减动效开关 / 文字可缩放 / 朗读兜底 —— 设计阶段定,测试阶段补 = 返工(见「无障碍闸门」)。
8. **进实现前先对账目标项目现状**并立项(勿重复已落地物;勿绕过引擎/语音/判分边界;见下「落到具体项目」)。

## 落到具体项目

本技能只含**通用视觉方法**,不含某游戏代码现状/接缝 —— 那类内容随代码漂移,归各项目文档维护。

- **前置 →** `game-story-design`(外貌锚 + 分支/演出钩子)定稿后再排视觉;缺外貌锚先回故事侧角色卡补,别在视觉侧另发明一套。
- **交棒 →** 素材 prompt 档 / 角色设定表产出后,回填点归**该项目设计文档**;技能与其它文档**只放指针**。
- 以本仓库(词库学习岛·千字谷)为例:现状接缝、角色注册、素材回填点与红线 → `docs/design/game-visual.md` + `docs/design/game-assets.md`,动手前先读并按其「先 grep 复核」执行。
- 其他项目同理:映射表放各自设计文档,勿写死在技能里。

## 无障碍闸门(设计稿就过,不留到测试)

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| 色彩冗余 | **永不只靠颜色**表达对错/状态 → 形状或图标冗余(红绿之外给 ✓/✗ 形) | 约 8% 男性红绿色盲;色盲看不出"红=错" |
| 减动效 | `prefers-reduced-motion` 兜底 + **显式开关**;视差/震屏/闪光**各自可关**(震屏含「关」档) | 前庭敏感者会真的难受,不是矫情 |
| 闪光 | 频闪**默认关** | 光敏性癫痫是硬风险 |
| 文字缩放 | 支持放大至 **2×**;正文 ≥ **18px** | 约 14% 成人阅读水平低于 11 岁 |
| 朗读 | 指令、题干、选项一律**可朗读**(有 TTS 通道 = 几乎零成本) | 儿童与阅读障碍者的主要通路 |
| 对比 | ≥ 4.5:1(见蓝图 WCAG 节) | — |

> 儿童向产品里,**无障碍 ≈ 可用性**,不是合规表演:孩子正是"不读字、看不懂状态色、手不稳"的那群用户。设计与 UI 阶段就落,测试阶段补是返工。

## 常见坑

1. **UI 先行反了**:先给 AI 跑图再定布局 → 头顶被切/塞不进。先画取景框再出 prompt。
2. **红/橙毛发角色绿幕溢绿边**:必须 `uniform lighting`,后期去饱和 + 色相偏移压掉。
3. **开心动作过火像蹦迪**:换成 `sways gently with breathing rhythm`(随呼吸轻摇),保叙事文静感。
4. **素材撞既有角色/资产**:跑图前查目标项目角色与资产注册表,勿造重复形象;新角色常跨语音/数据/测试域 → 先立项再谈素材。
5. **全屏网点/高饱和伤可读**:克制,网点 3-5% + 轻微噪点上限,保文字对比(儿童向尤甚)。
6. **逐句过度情绪标注**:情绪显著处才标(哭诉/恐吓/欢呼),其余走缺省,避免噪音。
7. **越硬性数值底线**:单气泡 ≤30 中字 / H1 拟声词图形化且 ≤画面 15% / 文字对比 ≥4.5:1 / 呼吸幅 ≤3% / 待机首尾差 <5% / UI hover ≤0.2s / 素材合包首屏 ≤3MB(流式另计)—— 破线 = 挡角色、赶读、廉价感。**数值权威与细则见上文「数值权威」注**;本行只是速查。
8. **把项目现状写死在通用技能里**:接缝/落点/红线属项目文档(本仓库 `docs/design/game-visual.md`),技能内只留方法论 —— 否则代码一演进技能就 stale。
9. **只给配方、不出素材 prompt 档**:项目方拿不到可直接外跑的 prompt → 要么每次重写漂移,要么锚点被塞进技能、甚至引用一个不存在的文件。**角色外貌锚与素材 prompt 的唯一事实源 = 项目设计文档**;技能与其它文档只放指针。缺外貌锚时先回 `game-story-design` 的角色卡补,别在视觉侧另发明一套。
10. **只出立绘不出设定表**:一张立绘只锁一个角度一个表情;换情绪时 AI 会**自行发明**刘海分缝、衣领形状、配饰位置。**3/4 侧视图 + 表情集 + 道具表 + 配色板** = 把"没说的"补成"已定的";儿童向尤其需要表情差分,否则角色说话只能顶一张脸。
11. **把无障碍留到测试阶段**:色盲/减动效/缩放/朗读是**设计决策**,不是后期开关 —— 构图先靠色、动效写死在组件里、文字用固定 px,后期就补不动了。设计稿阶段一并过。
