# 互动叙事:创作与结构(game-story-design)

## 定位与原则

故事 = 一个有代价的选择被反复推到极限。本技能管同一份交付的**两半 + 一块**:两半顺序不可倒,留痕附加。

| 块 | 管什么 | 参考 |
| --- | --- | --- |
| **创作** | 世界观 / 角色 / 场景 / 对白 / 伏笔 / 命名 | `references/script-and-craft.md` |
| **结构** | 逐幕演出表 / 节奏表 / 分支树 / 状态变量 / 结局可达性 / 存档兼容 | `references/structure-and-validation.md` |
| **留痕**(附) | 评审台账:闸门结论 + 版本锚 + 复评触发 | 本 SKILL「评审台账」 |

- **创作定稿再排结构**;上游未定稿就排分支 = 返工。
- **线性项目(无分支、单出口)照常适用**:只走「逐幕演出表 + 节奏表」;分支树、状态变量、结局多样性等项**标「不适用」并写明理由**,**禁虚构分支或结局来凑格式**。
- **结构模板 ≠ 填空处**:模板越整齐干净,漏得越多 —— 没列出来的(外貌锚、显影计划、跨章状态)才是最容易漏的。

**分工**:视觉演出与素材 → `game-visual-design`;听觉 → `game-audio-design`;阶段排程与跨域闸门 → `game-pipeline`。

## 创作纪律(速查)

| 领域 | 硬规矩 |
| --- | --- |
| 核心体验 | 先答「想让玩家**感受到**什么」(一个词)+ 情感曲线的谷底与回弹,再定情节;顺序倒了 = 空心故事 —— 热闹,但不打动人 |
| 前提与主题 | 先答「故事在**辩论**什么」;一句 logline = 谁 + 要什么 + 阻力 + 代价;主题命题写成「价值 + 因果」,**角色不得直接念出命题**(念出 = 命题未被戏剧化) |
| 玩法统一 | **玩法本身在讲故事**:机制、反馈、关卡、UI 都要表达主题 —— 故事歌颂守护、机制却逼玩家掠夺 = **叙事与玩法失调**;失调时改机制或改主题,别只改台词 |
| 世界规则 | 三条足够:如何运作 / **每次必付的代价**(不可豁免)/ 禁忌;规则用来生成冲突,定价后**禁中途改价**;反派受同一套规则约束 —— 能破例则规则作废 |
| 角色弧光 | 起点信念 → 破防点 → 终点;终局选择必须是第 1 幕做不到的那个;无弧光者降为功能位并**明标** |
| 场景 | 一场戏 = 目标 → 冲突 → 转折;**收场局面必须与开场不同**,否则删;先写「每屏一句人话」→ 再排选项 → **最后**才写台词 |
| 冲突升级 | 外部 / 内部 / 关系三条线,**至少一条逐章加码**(升级 = 代价变重,不是事件变多);三条都不涨 = 第二幕泄气 |
| 可玩性优先 | 故事**禁阻塞玩法**:可跳过 / 可回顾 / 有提示;玩家被剧情卡住 = 弃坑,儿童向尤甚 —— 故事是布景,不是路障 |
| 冰山配额 | 圣经写 10%、演出只用 1%;开场 3 屏**零**历史/体系旁白;每场最多 1 个新设定,一屏最多 1 个新专名 —— 观众记住的是**代价**,不是名词表 |
| 笑点 | 合格笑点 = 铺垫 + 意外 + **消解** + 良性 + 节奏 + **服务性**;缺消解 = 莫名其妙,解释笑话 = 当场死亡;**笑处境不笑人**,服务性 > 好笑;禁为笑点破世界规则 |
| 对白 | 潜台词:说的是愿意说的,不是真想的;情绪越强句子越短越偏;遮名测试(**功能性台词豁免**) |
| 硬线 | 单气泡 **≤ 30 中字**(含标点);**超线 = 砍句**,缩字只是 UI 保底 |

## 结构纪律(速查)

| 领域 | 硬规矩 |
| --- | --- |
| 能动性档位 | **先选档位再排节点**:线性 → 枢纽(主线固定,选择只影响关系/结局) → 分支 → 环境碎片 → 循环;档位越高成本越高,**默认选最低够用的档位**;不需要分支就老实线性 |
| 成本控制 | 分支必设**汇合点**、**复用场景**、**关键选择**(只让少数选择影响结局);无汇合的纯发散树 = 写不完也测不完 |
| 分支树 | 节点标「强制 / 可选 / QTE」;选项 2–4 个即可,宁可修剪;**每节点必有去向**(去向为空 = 死胡同);每个末端都能到某个结局 |
| 伪分支 | 选 A/B 至少一处不同(文案 / 状态 / 结局);三处全同 = 有选等于没选 |
| 结局 | 多结局项目:**≥3 条截然不同路径可达**,且每个预设结局都能被实际触发。项目不需要多结局时**老实写线性**,不造三个殊途同归的假结局 |
| 状态变量 | 宁少勿多(少量全局 + 少量标记足以撑起好故事);每行**有读有写、有结局落点**,禁悬空;玩家侧要可感知(别设「看不见的进度条」) |
| 节奏 | 起步值见结构侧 §二;**阶段 6 实测回填并反向修正该表** —— 别当固定真理 |
| 存档 | 存档带 `schemaVersion`(决定长期更新的最重要字段:存的不是"进度",是"哪一版规则下的进度");读取恒为四步「读版本 → 逐版迁移 → 校验 → 实例化」,迁移**只增不改、不可重排**,每版一个 `vN → vN+1` 纯函数 + 单测;未知/未来版本**优雅降级**(返回空而非抛错) |
| 内容迁移 | 增删节点留 `removedId → replacementId` 映射;未知 ID **降级为占位并保留原 ID**,别静默丢弃玩家做过的事;写入用**原子替换**(临时文件 + rename),崩溃后只可能是旧存档或新存档 |

> **内容更新与存档兼容是同一问题的两面。** 只排结构不管存档 = 加一章崩一批老玩家。

## 跨域约定(不可自行发明)

- **人称即分工**:叙述 / 过场 / 结果陈述 = **第三人称,无「我 / 我们」**;角色对白 = 第一 / 二人称。混用 = 叙述位形同虚设。
- **语域切换**:角色在剧情场面声纹浓,在**功能性台词**(操作指令、与判分/系统对齐的文本)切**中性腔** —— 这是有意设计(保读音干净与指令清晰),下游**不得当缺陷「修」掉**;遮名测试对功能性台词豁免。
- **台词权威只存一处(防漂移)**:分镜 / 演出文档**严禁复制台词、选项文本与题量** —— 只写意图;冲突时**以数据文件为准**。抄一份 = 造第二事实源,改台词时必漏其一。
- **外貌锚是跨域契约**:故事侧不写外貌 → 视觉侧与 AI 立绘无依据 → 两域必然漂移。锚点定稿后**只存一处**(项目设计文档),技能与其它文档只放指针,**禁引用不存在的位置**。
- **影子字段**:每字段必须能填出「演它的那一场」。填不出 = 删掉该栏或补一场戏;空栏 = 欠账。
- 配角的存在理由 = 给主角压力或作镜像;镜像角色(同困境、不同选择)胜过堆背景故事。

## 创作台账(两本,缺一不可)

- **伏笔台账**:埋了必收,收前必埋;每笔一行登记埋/收/回收方式。**无回收计划的伏笔 = 空头悬念**,删掉或补回收。
- **术语表(命名权威)**:专名跨章、跨文档只能有一份权威写法。**先入表再入稿**、一词一写法、禁同音近形撞车(儿童靠听认角色)、朗读可辨。项目已有「命名权威」节则**并入,不另起一份**。
  > 术语漂移是最贵的错误:一个专名定错,后续已配、已译、已画的资产全部跟着错。

## 质检闸门(定稿前逐项对账,进视觉前全过)

**故事层**(完整对账顺序见 `references/script-and-craft.md` §九)

| 检查 | 不过 = |
| --- | --- |
| 核心体验 + 主题命题各可一句说清,且无角色直接念出 | 空心 / 说教 |
| 玩法机制参与表达主题(不拆台) | 叙事与玩法失调 |
| 冲突至少一条线在加码 | 第二幕泄气 |
| 情感曲线有谷底有回弹(张弛交替) | 全程高潮 = 没有高潮 |
| 章节契约高潮位 / 笑点位已填;笑点过「消解 + 良性 + 服务性」三问 | 无高潮 / 无笑点 / 硬塞段子 |
| 世界规则过自洽三问(含反派同规则、极限推演) | 规则漂移,后期打脸 |
| 每场戏开场与收场状态不同 | 注水戏,删 |
| 主角终局选择 = 第 1 幕做不到的选择 | 无弧光 |
| 遮名测试通过(功能性台词豁免) | 对白无区分度 |
| 故事不阻塞玩法(可跳过 / 回顾 / 提示齐) | 剧情挡路 |
| 伏笔台账全部有回收 | 空头悬念 |
| 专名/术语全篇一种写法(对过命名权威表) | 跨章漂移,越往后越贵 |
| 无巧合解围、无天降救兵 | 廉价结局 |

**结构层**(骨架见 `references/structure-and-validation.md` §五)

| 检查 | 标准 | 不过 = |
| --- | --- | --- |
| 不可达死胡同 | 每个分支末端都能到某个结局 | 死路 |
| 伪分支 | 选 A/B 至少一处差异(文案 / 状态 / 结局) | 有选 = 没选 |
| 结局多样性 | 多结局项目 **≥3 条截然不同路径可达** | 单线伪装成多线 |
| 结局覆盖率 | 每个预设结局均可被实际触发(开发末实测) | 死循环 / 摆设结局 |
| 变量闭环 | 每个变量有读有写有结局落点 | 悬空变量 |
| 存档兼容 | 新增节点留 `removedId → replacementId`;`schemaVersion` 已升 | 加一章崩老档 |

> **线性项目(无分支)填法**:伪分支与结局多样性两项**标「不适用」并写明理由**(本章线性单出口,不存在兄弟节点可比 / 不预设多结局),**不虚构分支或结局凑格式**;其余各项照常适用 —— 线性项目反而更容易做到迁移零风险。

## 评审台账(闸门留痕,缺了等于没评)

闸门是**动作**,台账是**动作的结果**。只跑闸门不登记 = 下一个人重跑一遍,且分不清旧结论还有效没有。

> 本节是**流程台账**,与上文「创作台账」并列 —— 那两本记**作品内容**,这本记**评审结论**。

| 列 | 填什么 |
| --- | --- |
| 评审对象 | 设计文档 + **版本锚**(commit / 日期);对象被大改(角色集 / 世界观 / 幕数替换)= 旧评审**立即失效** |
| 依据 | 技能 + 闸门版本;**技能改过条款后,旧评审不自动继承新条款** —— 须复评 |
| 评审方 | **≠ 创作方**(至少换一个会话跑);同上下文自查 = 确认偏差 |
| 结论 | 逐项过 / 不过;不过项各一句话 |
| 处置 | 已落地(写落点)/ 入想法池占位 / **有意设计**(写明理由,防被当漏洞重提)/ 待定 |
| 复评触发 | 什么一变就重跑(例:角色集替换 / 幕数变 / 世界规则增删 / 技能条款更新) |

**四条铁律**:

- **入库**:台账与**评审记录本体**都写进项目设计文档;禁放 `docs/.tmp/` 等不入库路径 —— 不入库 = 换会话即断,而指针还留在圣经里骗人。
- **修上游指针**:动台账时同步修正指向它的地方(圣经 / PLAN / spec 的来源注),否则死指针继续把后人引向旧稿。
- **只增不删**:一行一次评审;对象作废标「**已失效(被 X 取代)**」,别删 —— 删了不知道哪些旧结论已被推翻。
- **不抄结论**:台账是**索引**(判定 + 落点),本体是**正文**;台账入库而本体留在 `.tmp` = 索引指向一个会消失的位置,与本条同病。

> 闸门管「这次过没过」,台账管「哪些结论还算数」。技能升级后**旧项目须按新条款复评一次**,标注增量结论 —— 否则技能在长,项目停在旧标准。

## 反模式(高危,写完自查)

1. **设定倾泻**:开场旁白讲体系/历史 → 让主角为规则付一次代价。
2. **代价漂移**:同一规则前后价码不同(为省剧情放水)。
3. **对白踩点**:「我现在很生气」「因为我们是朋友」 → 换行为 + 潜台词。
4. **工具人配角**:只递道具不挣扎 → 给镜像困境,或并入主角。
5. **漂亮台词优先**:先写台词后想情节 → 顺序倒过来。
6. **巧合解围**:巧合可以**制造**麻烦,不能**解决**麻烦。
7. **把圣经当交付物**:交付物永远是**能演出的脚本**,不是给人读的设定集。
8. **指令与高潮交给叙述位**:叙述框通常视觉最弱(小字/虚线/无角色名)→ **立刻照做的指令**与**情绪高潮**一律留在角色泡,叙述位只承载过场与铺垫。
9. **闭合枚举陷阱**:模板写死几栏 → 填完就以为完成,把**没列出来**的(外貌锚、显影计划、跨章状态)全挡在门外。用影子字段原则逼每栏都有演出落点;某栏长期没人填 = 删栏或补戏,别留作装饰。
10. **专名即兴**:写到手边随手造名、或同一物换着叫 → 跨章漂移,改名成本随章数/配音/翻译/立绘次第翻倍。先入表再入稿。
11. **分支膨胀**:节点选项无限加 → 成本指数级;回「分支树」纪律修剪。
12. **变量记不住**:为「看起来复杂」加变量 → 回「状态变量」纪律。
13. **文本密度硬线被豁免**:把超线当缩字处理 → 回「硬线」纪律(超线 = 砍句)。
14. **借叙事造引擎**:气泡造型交 `game-visual-design`;选项点击/推进走目标项目**既有交互组件**,勿另造一套。
15. **偏离已锚定世界观**:冒出的新点子先回阶段 0 重锚(见 `game-pipeline` 变更闸门),勿中途塞戏。
16. **玩法与故事打架**:机制奖励的行为与主题歌颂的价值相反 → 回「玩法统一」纪律;**光改台词治不好**。
17. **主角被动**:全程被剧情推着走、选择只剩「继续」→ 给主动目标 + 两难;被动主角 = 玩家看别人冒险。
18. **剧情挡路**:不可跳过的长过场、无提示的强制解谜、退出即丢进度 → 回「可玩性优先」纪律。
19. **学习失误 = 道德判决**:答错被写成「你没守住诺言 / 你害了它」→ 儿童把**技能失败**归到**人格**,生出羞耻与回避。**失败归因于技能,不归因于人格**;答错 → 给回应 + 引回正轨 + 可修复(结构侧 §五 注),别做成不可逆结局。
20. **评审不留痕**:结论散在聊天或不入库路径、对象作废不标、技能升级后不复评 → 回「评审台账」按四条铁律登记。
21. **笑点无消解 / 被解释**:只有意外没消解 = 莫名其妙;转折后补一句解释 → 回「笑点配方」(补消解、删解释)。
22. **笑点刻薄 / 硬塞 / 破规则**:笑人缺陷 = 冒犯;答不出「替谁干活」= 硬塞;为笑点破世界规则 = 规则作废 → 回「笑点配方」安全线。
