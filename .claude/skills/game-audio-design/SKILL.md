# 听觉设计(音景 + 反馈音 + 语音)

## 定位与原则

全屏漫画交互游戏的音频 = 两条腿:**环境音景**(氛围)+ **反馈音**(交互确认)。原则:**音为画服务、不抢戏、不遮对白**。

**分工**:角色声纹的**创作**在 `game-story-design`(声纹卡:句长/口头禅/禁用语);本技能负责把这些**转译成声音参数**(语速/音高/响度)。情绪符号的**视觉**在 `game-visual-design`,反馈音须与其**同源**。

> **数值权威**:本 SKILL 的闸门表即听觉域权威(≤4s / 响度归一 / 峰值限幅);项目可**加严**(儿童向更低峰值),加严写进项目文档并由测试守卫。

## 环境音景映射(场景情绪 → 音色)

按场景情绪挑持续音色,**别一首配乐走到底**:

| 场景情绪 | 音景示例 |
| --- | --- |
| 宁静田野/日常 | 风噪白噪、树叶窸窣 |
| 战斗/紧张 | 低频鼓点、脉冲 |
| 雨夜/回忆 | 雨声 + 闷雷 + 远钟 |

> 映射表是**起始示例**,按目标项目实际 scene/氛围字段转译,勿照搬。

## 反馈音效(交互确认)

- **触发点**:点击 / 悬停 / 翻页 / 情绪符号触发音。
- **设计**:短、轻、和情绪符号视觉**同源**;音量压低、不遮对白、不与角色待机音打架。

## 音频闸门(回填 / 上线前逐项过)

| 检查 | 标准 | 不过 = |
| --- | --- | --- |
| 时长 | 素材 ≤ **4s**,与 AI 视频循环(4s)对齐 | 超长易暴露循环切点 |
| 循环无缝 | 首尾**相位与响度**对齐,自检无爆点/咔哒声 | 循环处听得见接缝 |
| 响度 | 全素材**统一响度**归一;对白/语音轨道高于音景,**音景永不压过对白** | 玩家听不清台词 |
| 儿童向音量 | 峰值限幅,无突发大音量;首播有淡入,不惊吓 | 儿童向红线 |
| 语音规范 | 旁白/角色语音的语速与音高**逐角色区分**;与文本语义一致(数字、多音字连读自检) | 角色听不出差别 / 读错字 |
| 授权与来源 | 每件素材登记**来源与授权**(自产 / 授权曲库 / AI 生成),商用范围明确 | 上线后版权风险 |

## 语音(若有旁白或角色配音)

- **逐角色声纹**:语速 rate + 音高 pitch 按角色区分,并与故事侧的角色声纹卡**同源**(句长/口头禅)。
- **叙述位**:第三人称叙述句通常**语速更稳、音高更平**,与角色区分开;别用同一个嗓音包打全部。
- **功能性命中**:操作指令、判分相关文本的读音**必须准确优先于表现力**。
- 走浏览器 `SpeechSynthesis` 时:可用嗓音随平台不同 → 做好**回退**,别把某平台嗓音当设计事实。

## 常见坑

1. **一首配乐走到底**:场景情绪换了音景没换 → 氛围与画面脱节。
2. **反馈音太响/太多**:每次点击都给重音 → 盖过对白,玩家听觉疲劳。
3. **循环切点暴露**:素材超 4s 或首尾不对齐 → 每次循环都听见"咔哒"。
4. **角色共用一个嗓音**:逐角色 rate/pitch 没区分 → 听不出谁在说(儿童向尤甚,他们靠听认角色)。
5. **把某平台 TTS 嗓音当设计事实**:换平台即崩;必须写回退。
6. **授权登记后补**:上线前才发现某素材商用范围不明 → 返工或法务风险。

## 落到具体项目

本技能只含**通用听觉方法**。听觉要接某项目的音频系统(播放器 / 缓存 / 事件)时,**接缝与红线归该项目设计文档**(是否已有音频架构、儿童向音量规范、是否禁新增音轨等),动工前先查,勿在技能内假设。

- **前置 →** `game-story-design`:角色声纹卡先定稿,再转译成 rate/pitch;`game-visual-design`:反馈音与情绪符号同源。
- **交棒 →** 音频闸门通过后,回填点与授权登记归**该项目设计文档**;技能只放方法。
- **时序前置 →** `game-pipeline`「文本可逆线」:预生成音频 / 真人配音 / 本地化必须等**文本冻结之后**;运行时合成(浏览器 TTS)不落资产,不受此限。
