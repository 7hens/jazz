# 验收清单(并入 game-pipeline 总纲)

总纲的**守红线**三张表:硬约束速查、风险预案、里程碑验收。流程在 SKILL.md,数值与验收在这里。

## 一、六准则硬约束速查

> 权威细则 = `game-visual-design` 的 `references/blueprint.md`(文案密度 / 对比 / 出血安全区 / 性能预算)与 `references/ai-materials.md`(素材动作数值);**本表仅为速查,冲突以 references 为准**。

| 领域 | 硬线 |
| --- | --- |
| 视觉流向 | 视线 0.5s 内指对白落点(对角);文字区背景明度 < 40% |
| 出血/安全区 | 底 25% + 两侧 10% 不可侵犯;仅尾巴/头发/SFX 可出血 |
| 色彩无障碍 | 文字对比 ≥ 4.5:1(WCAG AA);**永不只靠颜色**(形状/图标冗余);情感色盘绑定(红=怒/橙=战,蓝=静) |
| 文本密度 | 单气泡 ≤ 30 中字;H1 拟声词图形化且 ≤ 画面 15% |
| AI 一致性 | 固定 seed + 锚点文本冻结 + Color Palette 硬编码;量大上 LoRA |
| 性能预算 | 首屏总包 ≤ 3MB(流式视频不计);视频渐进式加载 |

> 本表数值是**上限**,不是目标。项目可**加严**(如儿童向 / 朗读友好 → 单句 ≤20 字),加严须写进**项目文档**并由测试守卫,技能侧只留指针 —— 反之,项目声称的"已落地"若实际低于本表,即违规。

## 二、风险预案与回滚(域归属)

| 风险 | 触发 | 缓解 | 找谁 |
| --- | --- | --- | --- |
| 设定倾泻 / 对白踩点 | 开场讲体系;台词直陈情绪与立场 | 规则靠代价显形;遮名测试;行为代替陈述 | `game-story-design` |
| 代价漂移 / 无弧光 | 同规则前后价码不一;主角终局做的是第一幕就能做的事 | 规则定价后禁改;终局选择须是第一幕做不到的 | `game-story-design` |
| 叙事死循环/伪分支 | 分支殊途同归、有选=没选 | 阶段 6 结局覆盖率检测;≥3 条不同结局可达(线性项目标「不适用」,不虚构分支) | `game-story-design`(结构侧) |
| AI 基因漂移 | 同角色毛色/瞳/瞳孔跨镜头突变 | 固定 seed + 冻结锚点 + 注入固定色值;量大上 LoRA | `game-visual-design` |
| 音频与语音 | 循环爆点、旁白压过对白、儿童音量过载、素材授权不明 | 素材 ≤4s + 首尾相位对齐;响度/语音规范/授权登记见该技能闸门表 | `game-audio-design` |
| 文本溢出 | 30 字硬线被无视 | UI 层 shrink-to-fit 作保底,不豁免超线(砍句非缩字) | `game-visual-design` |
| 绿幕溢色 | 红/橙毛发边缘荧光绿 | 禁暴力抠除;Spill Suppression 替换环境色 | `game-visual-design` |
| 范围爆炸 / 素材返工 | 中途加角色或功能;跳过灰盒直接产成品素材 | 阶段 0 重锚 + 变更闸门;**先纵切片后批量** | 本技能(回退矩阵) |
| 无障碍缺位 | 对错只靠颜色;动效无降级;提示全靠读字 | 形状/图标冗余;减动效开关;朗读兜底 | `game-visual-design` |
| 隐私 / 儿童合规 | 埋点、第三方 SDK、持久标识符 | **默认零遥测**;若对外发布先过合规门 | 本技能(`references/production-gates.md`) |
| 存档不兼容 | 内容更新后旧存档崩 / 进度被重置 | 存档带 `schemaVersion`,迁移只增不改 | `game-story-design`(结构侧) |
| 文本改在录音之后 | 台词未冻结就录了音 | **文本可逆线**:先冻文本再产音频(运行时 TTS 免此限) | 本技能(文本可逆线) |

## 三、里程碑验收清单(跨域收口)

| 里程碑 | 交付 | 验收 |
| --- | --- | --- |
| M0 概念定稿 | 一页定位(类型 / 平台 / 风格锚 / **内容预算**) | 后续任何偏离先回此步重锚;缺此步 = 变更无锚 |
| M1 叙事定稿 | 故事侧:世界观圣经 + **角色台账** + 分镜脚本表 + 伏笔台账 + **术语表**;结构侧:**逐幕演出表** + 分支树 + 状态变量表 | 过 `game-story-design` 双闸门(故事层 + 结构层逻辑校验,验收细则在该技能两处,本表不复述);对白过遮名测试 |
| M2 UI 定稿 | 高保真稿 + 设计规范 + **角色设定表**(3/4 侧视/表情集/配色板) | 过对比度与无障碍闸门;组件库完整;设定表无"没写到的情绪" |
| M3 AI 资产库 | 角色立绘(含情绪符号/**表情差分**)+ 场景 + 4s 动作视频 | 过三无 + 风格一致;角色一致性达标 |
| M3.5 纵切片 | 1 幕**成品级**(全通道)+ 占位灰盒覆盖全篇 | 启动/重开/失败恢复/存档四路可跑;未过**禁进阶段 4** |
| M4 可玩原型 | ≥3 幕完整串联(复用纵切片规格) | 首屏 ≤3s;音频同步;分支跳转正常 |
| M5 测试调优 | 测试报告 + 节奏调整 + 结局覆盖率 + 儿童试玩 | 所有结局路径可达;停留时长符节奏表;**≥3 名儿童试玩且不依赖读字** |
| M6 上线 | 构建产物 + 已打 tag + 回滚预案 | 迁移**先升库后升代码**;浏览器冒烟通过**之后**才打 tag(失败绝不 version,孤儿 tag = 回滚失锚);回滚路径可执行 |
