# 先验环与守门(并入 game-pipeline 总纲)

总纲阶段 3b / 6 / 8 的细则:**先验**(灰盒、纵切片、试玩)与**守门**(合规、预算)。

## 一、灰盒排演(blockout)

**原则:`blockout → 试 → 迭代 → 穿衣;永不「素材先行」。**

- 用色块/占位图把**全篇每一幕**排一遍(布局/交互/转场/停留时长),此阶段改一处 = 秒级。
- 灰盒验的是**循环与节奏**,不是好不好看。
- 宁要 10 个丑灰盒,不要 1 个提前精修的失败幕 —— 精修过的幕舍不得删,那才是沉没成本陷阱。

## 二、纵切片(vertical slice)

**定义**:挑 1 幕(通常第 1 章第 1 幕)做到**成品级**,把**整条管线**跑通一遍。

必须包含(缺一即不算):

| 项 | 内容 |
| --- | --- |
| 全通道 | 背景/角色/UI/音频/字体/特效 **均达成品质量**,不留"以后再补" |
| **四路可跑** | 启动(startup)· 重开(restart)· **失败恢复**(failure recovery)· 关闭(shutdown) |
| 真存档 | 存 → 退出 → 读 → 续玩,并至少覆盖一次**失败后重试** |
| 双向 | 一次完整通关 **+** 一次完整失败 |

**反模式「英雄模式」(hero mode)**:用不可持续的人力/时长堆出来的切片 —— 它证明不了真实产能,只证明你能熬。切片须按**日后实际节奏**做,才测得准工期。

**为什么值得**:「一小块成品 > 一大块原型」。切片把「不好玩 / 管线不通 / 性能不达标 / 工期估错」四类问题,从 **80% 完成度提前到 5%** 暴露。

**切片即参考套件**:后续各幕按它的规格复制(镜头/间距/气泡/时长/文件规格),别重新发明。

## 三、儿童试玩(阶段 6,≥3 人/章)

**前提:孩子不读字。** 观察法:

- think-aloud,**家长在场**,单次 20–40 min;别问「好不好玩」(孩子一律说好),记录**他实际点了什么**。
- 已知必坏处(实测结论,直接按此设防):
  - 学龄前儿童**完全忽略屏上文字**,靠试错与探索推进 → 提示/按钮/教程一律要**图 + 音 + 动效**兜底。
  - **听懂 ≠ 认得出**:孩子听音频知道答案,却对不上对应的**文字选项** —— 朗读与文字匹配是两件事,别混为一谈。
  - 拖拽类操作失败率高 → 必须有点选替代路径。
  - 答错只说「错」不够,孩子需要**「为什么错」**。
- 记「卡住点」比记「喜欢点」有用;**上一章的卡住点 = 下一章的简报**。

## 四、隐私与儿童合规门(对外发布前)

> 单机自托管 + 单档案 + 零第三方 SDK = **最强姿态**。把「零遥测」当**资产**写进文档,别当缺口。

- 若对外发布:收集任何数据前加**中立年龄门** + 隐私政策;**分析 SDK 默认采集设备 ID 与 IP**,能不用就不用。
- **分级 ≠ 合规**:ESRB / PEGI / IARC 是**内容分级**,不解决隐私问题。
- 儿童向红线:行为广告、跨应用追踪、画像默认开启 —— 一律禁止(IARC 问卷免费,覆盖商店分级)。
- 埋点(阶段 8 数据回灌)先答四问:**收什么 / 存哪 / 谁能看 / 留多久**?答不上 = 不做。

## 五、资产清单与内容预算(防范围蔓延)

- **资产清单**:每类素材一行(立绘 / 表情差分 / 布景元素 / 氛围 / 符号 / 音频),含**数量 × 状态**,存项目设计文档。没有清单 = 无法估工 = 范围失控。
- **内容预算**:立项时给全篇一个**量级**(几幕 / 几角色 / 几套布景),超出即回阶段 0 重估 —— 变更闸门只挡「擅自加」,**预算表挡「慢慢涨」**。
- **AI 素材预期返工率 20–30%**:按批量估工,别按 1:1 估。
